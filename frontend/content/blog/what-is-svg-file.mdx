## SVG 파일이란?

**SVG(Scalable Vector Graphics)** 는 W3C가 표준화한 XML 기반 **벡터 이미지 형식**입니다. 픽셀(점)의 집합으로 이미지를 저장하는 PNG·JPG와 달리, SVG는 수학적 좌표·경로·도형 정보를 텍스트로 저장합니다. 덕분에 어떤 크기로 확대하거나 축소해도 이미지가 전혀 흐릿해지지 않습니다.

웹 아이콘, 브랜드 로고, UI 일러스트, 데이터 차트 등 **선명도와 확장성이 중요한 모든 곳**에서 SVG가 사용됩니다.

## SVG vs PNG vs JPG — 한눈에 비교

| 비교 항목 | SVG | PNG | JPG |
|-----------|-----|-----|-----|
| 저장 방식 | 벡터(XML 코드) | 비트맵(픽셀) | 비트맵(픽셀) |
| 확대 품질 | 손실 없음 (무한 확대 가능) | 깨짐 발생 | 깨짐 발생 |
| 투명 배경 | 지원 | 지원 | 미지원 |
| 애니메이션 | CSS·JS로 가능 | 불가 | 불가 |
| 편집 가능성 | 텍스트 편집기로 수정 가능 | 이미지 편집기 필요 | 이미지 편집기 필요 |
| 파일 크기 (로고/아이콘) | 매우 작음 | 보통 | 작음 |
| 파일 크기 (사진) | 매우 큼 (비권장) | 큼 | 가장 작음 |
| 웹 SEO | 내부 텍스트 인식 가능 | 불가 | 불가 |
| 주요 용도 | 아이콘, 로고, UI, 차트 | 투명 이미지, UI | 사진, 풍경 |

> **핵심 요약:** 로고·아이콘처럼 단순하고 선명해야 하는 이미지 → **SVG**, 사진처럼 색상이 복잡한 이미지 → **JPG**가 최선입니다.

## SVG 파일의 5가지 핵심 장점

### 1. 해상도 독립 — 어떤 크기에서도 선명

SVG는 수식으로 그린 그림이기 때문에 스마트폰 화면(360px)부터 대형 현수막(수 미터)까지 단 하나의 파일로 대응합니다. 레티나·4K 디스플레이에서도 픽셀이 무너지지 않습니다.

### 2. 파일 크기 절감으로 웹 성능 향상

단순한 아이콘이나 로고는 SVG가 PNG 대비 파일 크기가 70~90% 더 작은 경우가 많습니다. 페이지 로딩 속도가 빨라지고 Core Web Vitals(LCP) 점수에도 유리합니다.

### 3. CSS·JavaScript로 동적 제어

SVG는 코드(XML)이기 때문에 `fill`, `stroke`, `transform` 속성을 CSS나 JS로 실시간으로 바꿀 수 있습니다. 다크 모드 아이콘 자동 전환, 호버 애니메이션, 데이터 기반 차트 업데이트가 모두 가능합니다.

### 4. 검색엔진(SEO) 친화적

SVG 내부에 `<title>`, `<desc>` 태그로 설명을 삽입하면 구글이 이미지 내용을 텍스트로 인식합니다. 이미지 검색 노출에 직접적으로 유리합니다.

### 5. 텍스트 편집기로 직접 수정 가능

VS Code, 메모장 등으로 SVG 파일을 열면 색상 코드(`#FF5733`), 크기(`width="200"`), 경로 좌표를 직접 수정할 수 있습니다. 디자인 도구 없이 빠른 수정이 가능합니다.

1. 변환할 이미지(PNG / JPG / WebP)를 준비합니다.
2. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에 접속해 파일을 드래그 앤 드롭합니다.
3. 변환이 완료되면 **SVG 파일을 즉시 다운로드**합니다.

설치 불필요, 로그인 불필요, 완전 무료입니다. 로고·아이콘처럼 색상이 단순할수록 변환 품질이 높습니다.

## FAQ

### Q. SVG 파일은 어떤 프로그램으로 열 수 있나요?
A. Chrome, Firefox, Safari, Edge 등 모든 현대 브라우저에서 바로 열립니다. 편집은 **피그마(무료)**, Adobe Illustrator, **Inkscape(오픈소스 무료)**로 할 수 있으며, 텍스트 편집기(VS Code, 메모장)로도 코드 수준 편집이 가능합니다.

### Q. 사진(인물, 풍경)도 SVG로 변환할 수 있나요?
A. 기술적으로는 가능하지만 **권장하지 않습니다.** 수천 가지 색상이 담긴 사진을 SVG로 변환하면 파일 크기가 오히려 수십 배 커지고 품질도 떨어집니다. SVG는 색상이 단순한 **로고·아이콘·일러스트**에 최적화되어 있습니다.

### Q. SVG 파일을 PNG로 다시 바꿀 수 있나요?
A. 네. ① 브라우저에서 SVG를 열고 우클릭 → 이미지를 다른 이름으로 저장, ② Inkscape의 '비트맵으로 내보내기' 기능, ③ 온라인 SVG→PNG 변환 도구를 활용하면 됩니다.

### Q. SVG는 모든 브라우저에서 지원되나요?
A. Internet Explorer 8 이하를 제외한 **모든 현대 브라우저**에서 완벽히 지원됩니다. 2026년 현재 IE 점유율은 0.1% 미만이므로 실무에서는 호환성 걱정 없이 사용할 수 있습니다.

### Q. SVG 파일 내부 코드를 직접 편집하면 어떤 게 가능한가요?
A. `fill="#색상코드"`로 색상 변경, `width`·`height` 속성으로 기본 크기 조정, `<animate>` 태그로 간단한 움직임 추가, `viewBox`로 크롭 영역 조정 등이 가능합니다. 코드를 알면 알수록 SVG는 강력한 도구가 됩니다.

### Q. AI·디자인 도구 없이 SVG를 만들 수 있나요?
A. 가장 쉬운 방법은 **기존 PNG·JPG를 자동 변환**하는 것입니다. [imgtosvg](https://img-to-svg-six.vercel.app)에 이미지를 올리면 수초 안에 SVG가 생성됩니다. 단순한 로고나 아이콘은 별도 디자인 작업 없이 바로 사용할 수 있는 품질로 나옵니다.
