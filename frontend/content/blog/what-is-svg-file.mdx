## SVG 파일이란?

**SVG(Scalable Vector Graphics)**는 W3C가 표준화한 XML 기반 **벡터 이미지 포맷**입니다. PNG·JPG처럼 픽셀(점)의 집합이 아니라, 수학적 좌표·경로·도형 정보를 텍스트 코드로 저장합니다. 덕분에 어떤 크기로 확대하거나 축소해도 이미지가 절대 흐릿해지지 않습니다.

스마트폰 화면(360px)부터 대형 옥외 광고판(수 미터)까지 **단 하나의 파일**로 선명하게 대응할 수 있어, 브랜드 로고·UI 아이콘·인포그래픽에서 사실상 표준 포맷으로 자리잡았습니다.

## SVG 파일 내부 구조 살펴보기

SVG는 일반 텍스트 파일이기 때문에 메모장이나 VS Code로 열면 아래와 같은 XML 코드가 보입니다.

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" fill="#4A90E2" />
  <text x="50" y="55" text-anchor="middle" fill="white" font-size="14">SVG</text>
</svg>
```

- `viewBox` — 내부 좌표계 정의 (크기에 독립적)
- `<circle>` — 수학적 원 도형
- `fill` — CSS로도 제어 가능한 색상 속성

코드를 직접 편집하면 별도 디자인 도구 없이도 색상·크기·형태를 즉시 바꿀 수 있어 개발자와 디자이너 모두에게 강력한 도구입니다.

## SVG vs PNG vs JPG vs WebP — 4가지 포맷 완전 비교

| 비교 항목 | SVG | PNG | JPG | WebP |
|-----------|-----|-----|-----|------|
| 저장 방식 | 벡터(XML 코드) | 비트맵(픽셀) | 비트맵(픽셀) | 비트맵(픽셀) |
| 확대 품질 | 손실 없음 (무한 확대) | 깨짐 발생 | 깨짐 발생 | 깨짐 발생 |
| 투명 배경 | 지원 | 지원 | 미지원 | 지원 |
| 애니메이션 | CSS·JS로 가능 | 불가 | 불가 | 지원 |
| 코드 편집 | 텍스트 편집기로 수정 가능 | 불가 | 불가 | 불가 |
| 파일 크기 (로고) | 매우 작음 (5~20KB) | 보통 (50~200KB) | 작음 | 작음 |
| 파일 크기 (사진) | 매우 큼 (비권장) | 큼 | 가장 작음 | 작음 |
| SEO 최적화 | 내부 텍스트 인식 가능 | 불가 | 불가 | 불가 |
| 브라우저 지원 | 모든 현대 브라우저 | 모든 브라우저 | 모든 브라우저 | 모든 현대 브라우저 |
| 주요 용도 | 로고, 아이콘, UI, 차트 | 투명 이미지, UI | 사진, 풍경 | 웹 이미지 전반 |

> **핵심 요약:** 로고·아이콘처럼 단순하고 선명해야 하는 이미지 → **SVG**, 색상이 복잡한 사진 → **JPG 또는 WebP**가 최선입니다.

## SVG 파일의 핵심 장점 7가지

### 1. 무한 확대에도 선명 — 해상도 독립

SVG는 수식으로 그린 그림이라 스마트폰(360px)부터 4K 모니터, 인쇄물(수백 dpi)까지 단 하나의 파일로 완벽 대응합니다. 레티나·HiDPI 디스플레이에서도 픽셀이 깨지지 않습니다.

### 2. 파일 크기 절감 → 웹 성능 향상

단순한 아이콘·로고는 SVG가 PNG보다 파일 크기가 70~90% 작은 경우가 많습니다. 페이지 로딩 속도가 빨라지고 Google Core Web Vitals(LCP) 점수 향상에도 유리합니다.

### 3. CSS·JavaScript로 동적 제어

SVG는 코드(XML)이기 때문에 `fill`, `stroke`, `transform` 속성을 CSS·JS로 실시간 변경할 수 있습니다. 다크 모드 아이콘 자동 전환, 호버 애니메이션, 데이터 기반 차트 업데이트가 한 파일로 가능합니다.

### 4. 검색엔진(SEO) 친화적

SVG 내부에 `<title>`, `<desc>` 태그로 설명을 넣으면 구글이 이미지 내용을 텍스트로 인식합니다. 이미지 검색 노출과 접근성 향상에 직접적인 이점을 줍니다.

### 5. 텍스트 편집기로 직접 수정 가능

VS Code, 메모장 등으로 SVG 파일을 열면 `fill="#FF5733"` 같은 색상 코드, `width`·`height` 크기, 경로 좌표를 바로 수정할 수 있습니다. 별도 디자인 도구 없이도 빠른 커스터마이징이 가능합니다.

### 6. 피그마·Illustrator와 완벽 호환

SVG는 피그마, Adobe Illustrator, Inkscape 등 주요 디자인 툴의 기본 내보내기·불러오기 형식입니다. 디자인 협업 시 화질 손실 없이 파일을 주고받을 수 있습니다.

### 7. 접근성(Accessibility) 향상

`<title>`, `<desc>`, `aria-label` 속성을 추가하면 스크린 리더가 SVG 이미지를 설명할 수 있어, 웹 접근성(WCAG) 기준을 충족하는 데 도움이 됩니다.

## SVG 파일은 어디에 쓰이나요?

### 웹·앱 개발
- **UI 아이콘** — 버튼, 메뉴, 소셜 미디어 아이콘 세트
- **스프라이트 시트** — 여러 아이콘을 하나의 SVG에 통합해 HTTP 요청 최소화
- **로딩 애니메이션** — CSS keyframe으로 부드러운 스피너 구현

### 디자인·마케팅
- **브랜드 로고** — 인쇄물과 디지털 모두 단일 파일로 활용
- **인포그래픽·데이터 차트** — D3.js, Chart.js와 결합해 동적 시각화
- **이메일 서명·뉴스레터** — 고해상도 유지가 필요한 로고 삽입

### 출판·인쇄
- **명함·포스터** — 해상도 제약 없이 고품질 출력
- **PPT·Keynote 삽입** — 확대해도 선명한 다이어그램

## PNG·JPG·WebP를 SVG로 변환하는 방법

기존 래스터 이미지를 SVG로 변환하려면 **이미지 트레이싱(자동 벡터라이징)** 도구를 사용합니다. 색상이 단순한 로고·아이콘일수록 변환 품질이 뛰어납니다.

### 변환 품질을 높이는 팁

| 조건 | 권장 사항 |
|------|-----------|
| 배경색 | 흰색 또는 투명 배경 선호 |
| 색상 수 | 16색 이하일수록 깔끔한 결과 |
| 해상도 | 원본 해상도가 높을수록 유리 |
| 이미지 종류 | 로고·아이콘·일러스트에 최적, 사진 비권장 |
| 파일 크기 | 10MB 이하 권장 |

### 빠른 3단계 변환 방법

1. 변환할 이미지(PNG / JPG / WebP)를 준비합니다.
2. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에 접속해 파일을 드래그 앤 드롭합니다.
3. 변환 완료 후 **SVG 파일을 즉시 다운로드**합니다.

설치·로그인 불필요, 완전 무료입니다. 배경 제거 기능도 내장되어 있어 투명 배경 SVG를 한 번에 얻을 수 있습니다.

## FAQ

### Q1. SVG 파일은 어떤 프로그램으로 열 수 있나요?

Chrome, Firefox, Safari, Edge 등 모든 현대 브라우저에서 즉시 열립니다. 편집은 **피그마(무료)**, Adobe Illustrator, **Inkscape(오픈소스 무료)**, VS Code로 할 수 있습니다. 단순 확인이라면 파일을 브라우저로 드래그하는 것만으로 충분합니다.

### Q2. 사진(인물, 풍경)도 SVG로 변환하면 좋을까요?

기술적으로는 가능하지만 **권장하지 않습니다.** 수천 가지 색상이 담긴 사진을 SVG로 변환하면 파일 크기가 오히려 수십 배 커지고 품질도 저하됩니다. SVG는 색상이 단순한 **로고·아이콘·일러스트**에 최적화되어 있습니다.

### Q3. SVG 파일을 PNG로 다시 변환할 수 있나요?

네. ① 브라우저에서 SVG를 열고 우클릭 → '이미지를 다른 이름으로 저장', ② Inkscape의 '비트맵으로 내보내기', ③ 온라인 SVG→PNG 변환 도구를 활용하면 됩니다. 원하는 해상도를 직접 지정해서 내보낼 수 있습니다.

### Q4. SVG는 보안 위험이 있나요?

SVG 내부에 JavaScript(`<script>` 태그)를 삽입할 수 있어, 신뢰할 수 없는 출처의 SVG를 웹에 인라인으로 삽입하면 XSS 취약점이 생길 수 있습니다. `<img>` 태그로 불러오거나 서버에서 SVG를 새니타이징(sanitize)하는 것이 안전합니다.

### Q5. SVG 파일 크기를 줄이는 방법은?

**SVGO(SVG Optimizer)** 같은 도구로 불필요한 메타데이터·공백·주석을 제거하면 파일 크기를 20~60% 줄일 수 있습니다. Vite, webpack 플러그인으로 빌드 시 자동 최적화하는 것을 권장합니다. 온라인 SVGO 도구도 무료로 이용 가능합니다.
