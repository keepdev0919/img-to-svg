## 투명 배경 PNG vs 투명 배경 SVG — 무엇을 선택해야 할까?

| 특성 | 투명 PNG | 투명 SVG |
|------|----------|----------|
| 파일 크기 | 큼 | 작음 |
| 확대 시 품질 | 픽셀 깨짐 | 선명 유지 |
| 웹 성능 | 보통 | 우수 (빠른 로딩) |
| 인쇄 해상도 | DPI 제한 | 무제한 해상도 |
| CSS/JS 편집 | 불가 | 가능 |
| SEO 친화성 | 낮음 | 높음 |

로고, 아이콘, 일러스트처럼 선명함이 중요한 이미지는 **SVG 형식**이 장기적으로 훨씬 유리합니다. 특히 반응형 웹 디자인과 고해상도(Retina) 디스플레이 대응에는 SVG가 표준입니다.
