## 투명 PNG vs 투명 SVG — 어느 형식이 더 나을까?

배경을 제거한 후 PNG로 저장할지, SVG로 저장할지 고민되신다면 이 표를 참고하세요.

| 비교 항목 | 투명 PNG | 투명 SVG |
|-----------|----------|----------|
| 파일 크기 | 큼 (수 MB 가능) | 작음 (수십~수백 KB) |
| 확대 시 품질 | 픽셀화 (품질 저하) | 항상 선명 |
| 웹 로딩 속도 | 느릴 수 있음 | 빠름 |
| 인쇄 해상도 | DPI 제한 있음 | 무제한 해상도 |
| CSS로 색상 변경 | 불가 | 가능 |
| 애니메이션 적용 | 불가 | 가능 |
| SEO 이미지 검색 | 보통 | 높음 |
| 반응형 디자인 | 불편 | 완벽 지원 |

로고, 아이콘, 브랜드 자산처럼 **다양한 크기와 환경에서 사용하는 이미지는 SVG가 압도적으로 유리**합니다. PNG는 사진처럼 복잡한 색상이 많은 이미지에 적합합니다.

## 자주 묻는 질문 (FAQ)

### Q1. 머리카락처럼 세밀한 부분도 잘 제거되나요?

AI 도구는 머리카락이나 털처럼 복잡한 경계선도 상당히 잘 처리합니다. 단, 배경색과 피사체 색이 비슷한 경우 정확도가 낮아질 수 있습니다. 이 경우 단색(흰색, 파란색 등) 배경에서 찍은 원본 이미지를 사용하면 훨씬 좋은 결과를 얻을 수 있습니다.

### Q2. 이미지 크기 제한이 있나요?

imgtosvg는 대부분의 일반적인 이미지 파일을 처리할 수 있습니다. 지나치게 큰 파일(수십 MB 이상)은 변환 시간이 길어질 수 있으나, 일반 카메라나 스마트폰으로 찍은 사진은 대부분 문제없이 처리됩니다.

### Q3. 업로드한 이미지가 서버에 저장되나요?

imgtosvg는 변환 처리 후 이미지를 서버에 보관하지 않습니다. 개인 사진이나 기업 기밀 자료도 안심하고 사용할 수 있습니다.

### Q4. 배경 제거 없이 SVG 변환만 할 수도 있나요?

네, 가능합니다. "배경 제거" 옵션을 체크하지 않으면 원본 이미지 그대로 SVG로 변환됩니다. 배경 제거와 SVG 변환을 각각 또는 동시에 선택해서 사용할 수 있습니다.

### Q5. 무료로 몇 번까지 사용할 수 있나요?

imgtosvg는 완전 무료 서비스로 사용 횟수에 제한이 없습니다. 회원가입도 필요 없어 접속 즉시 바로 사용할 수 있습니다.
