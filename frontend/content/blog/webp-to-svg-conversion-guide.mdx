## WebP란? 왜 SVG로 변환해야 할까?

**WebP**는 Google이 개발한 차세대 이미지 포맷입니다. PNG·JPG보다 파일 크기가 평균 25~34% 작으면서도 화질이 우수해 웹 성능 최적화에 널리 쓰입니다. 하지만 WebP는 *래스터(픽셀) 이미지*이기 때문에 확대하면 픽셀이 깨지는 한계가 있습니다.

**SVG(Scalable Vector Graphics)**는 수학적 경로로 그래픽을 정의합니다. 100px이든 10,000px이든 항상 선명하고, CSS·JavaScript로 색상이나 크기를 동적으로 바꿀 수도 있습니다. 로고·아이콘·일러스트를 웹이나 인쇄물에 활용한다면 SVG가 훨씬 유리합니다.

---

## WebP vs SVG — 한눈에 비교

| 비교 항목 | WebP | SVG |
|---|---|---|
| 이미지 방식 | 래스터 (픽셀) | 벡터 (수학 경로) |
| 확대 시 품질 | 픽셀 깨짐 발생 | 무한 확대 선명 |
| 파일 크기 | 작음 (압축 우수) | 단순 이미지는 매우 작음 |
| 사진 표현 | 우수 | 부적합 |
| 로고·아이콘 | 보통 | 최적 |
| CSS/JS 조작 | 불가 | 가능 |
| 인쇄 해상도 | 제한적 | 완벽 |
| 브라우저 지원 | 모든 최신 브라우저 | 모든 최신 브라우저 |
| SEO 활용 | 이미지 alt 텍스트만 | 텍스트 포함 가능 |

> **결론:** 웹 사진·배너는 WebP, 로고·아이콘·일러스트·UI 요소는 SVG가 적합합니다.

## WebP를 SVG로 변환하기 좋은 경우

SVG 변환은 **모든 이미지에 적합하지 않습니다.** 아래 경우에 특히 효과적입니다.

- **로고·브랜드 마크** — 확대해도 선명하게 유지
- **아이콘·픽토그램** — 색상이 명확히 구분된 단순 이미지
- **손그림 스케치·일러스트** — 선이 또렷한 이미지
- **QR 코드·바코드** — 고해상도 인쇄 필요 시
- **다이어그램·플로우차트** — 벡터 편집 필요 시

반면 사람 얼굴 사진이나 복잡한 그러데이션이 많은 이미지는 변환 결과가 만족스럽지 않을 수 있습니다.

## 자주 묻는 질문 (FAQ)

### Q1. WebP를 SVG로 변환하면 화질이 유지되나요?

SVG는 벡터 형식이기 때문에 변환 후에는 어떤 크기로 확대해도 선명하게 유지됩니다. 단, 원본 WebP 이미지가 복잡할수록 경로 표현이 단순화될 수 있습니다. 로고·아이콘처럼 단순한 이미지에서 가장 좋은 결과를 얻을 수 있습니다.

### Q2. imgtosvg는 완전 무료인가요?

네, [imgtosvg](https://img-to-svg-six.vercel.app)는 가입 없이 무제한으로 무료 사용할 수 있습니다. 별도의 프리미엄 플랜이 없으며, 광고 없이 깔끔한 환경에서 변환할 수 있습니다.

### Q3. 변환된 SVG 파일을 피그마에서 사용할 수 있나요?

네, 표준 SVG 파일을 생성하기 때문에 피그마, Adobe Illustrator, Inkscape, Sketch 등 모든 주요 디자인 툴에서 바로 열거나 드래그 앤 드롭으로 가져올 수 있습니다.

가능합니다. 배경 제거 옵션을 활성화하면 AI가 자동으로 배경을 제거하고 주요 오브젝트만 SVG로 추출합니다. 흰 배경 로고에 특히 효과적입니다.

### Q5. 변환할 수 있는 파일 크기 제한이 있나요?

일반적인 웹 이미지 크기(수 MB 이하)는 모두 처리 가능합니다. 매우 크거나 복잡한 이미지는 변환 시간이 다소 걸릴 수 있습니다.
