## SVG vs PNG — 2026년에도 헷갈리는 포맷 선택, 이 글 하나로 끝내기

"이 이미지, SVG로 써야 해? PNG로 써야 해?" 디자이너와 개발자 모두가 반복하는 질문입니다. 두 포맷은 이미지를 저장하는 방식 자체가 달라서, 잘못 선택하면 화질 손상·파일 용량 폭증·SEO 불이익·인쇄 품질 저하까지 이어질 수 있습니다. 이 가이드에서는 7가지 핵심 관점으로 두 포맷을 완전히 비교하고, 상황별 최선의 선택 기준을 명확히 정리합니다.

---

## SVG란 무엇인가?

**SVG(Scalable Vector Graphics)** 는 XML 코드로 이미지를 표현하는 **벡터 포맷**입니다. 픽셀 대신 수학적 좌표와 경로(path)로 도형을 정의하기 때문에 어떤 해상도에서도 선명하게 렌더링됩니다. 파일을 텍스트 에디터로 열면 `<circle>`, `<path>`, `<rect>` 같은 태그를 확인할 수 있습니다.

### SVG 대표 장점

- **무한 확대 가능** — 4K 모니터, 스마트워치, 대형 현수막 모두 선명
- **파일 크기 작음** — 단순 도형은 수 KB 수준
- **CSS·JavaScript 제어** — 애니메이션, 색상 변경, 인터랙션 구현
- **SEO 친화적** — `<title>`, `<desc>` 태그로 의미 부여 가능
- **텍스트 기반** — Git으로 버전 관리, 검색엔진이 내용 파악 가능

### SVG 대표 단점

- 사진처럼 픽셀이 복잡한 이미지는 파일 크기가 오히려 커짐
- 일부 레거시 소프트웨어·이메일 클라이언트에서 미지원
- 래스터 기반 편집 툴(포토샵 등)에서 직접 수정이 어려움

---

## PNG란 무엇인가?

**PNG(Portable Network Graphics)** 는 픽셀 단위로 색상 정보를 저장하는 **래스터 포맷**입니다. 무손실 압축과 투명 배경(알파 채널)을 지원해 UI 스크린샷, 복잡한 그래픽, 반투명 요소 표현에 강점이 있습니다.

### PNG 대표 장점

- **투명 배경(알파 채널)** 완벽 지원 — 합성·오버레이에 유리
- **모든 색상·그라데이션** 정밀 표현
- **범용 호환성** — 어느 소프트웨어, 브라우저, OS에서나 열림
- **무손실 압축** — JPEG와 달리 저장할수록 화질 열화 없음

### PNG 대표 단점

- 확대하면 픽셀이 깨짐 (해상도 종속)
- 고해상도 이미지는 파일 크기가 커짐
- 애니메이션 미지원 (APNG는 별도 포맷)

## SVG vs PNG — 7가지 핵심 비교표

| 비교 항목 | SVG | PNG |
|---|---|---|
| **이미지 방식** | 벡터 (수식·경로 기반) | 래스터 (픽셀 기반) |
| **해상도 독립성** | ✅ 무한 확대 선명 | ❌ 확대 시 픽셀 깨짐 |
| **투명 배경** | ✅ 지원 | ✅ 지원 |
| **파일 크기** | 단순 도형 → 매우 작음 | 해상도·색상 수에 비례 |
| **애니메이션** | ✅ CSS/JS로 가능 | ❌ 기본 미지원 |
| **사진 표현력** | ❌ 부적합 | ✅ 우수 |
| **웹 성능(Core Web Vitals)** | ✅ 가볍고 빠름 | 용량에 따라 영향 |
| **SEO 최적화** | ✅ 텍스트 기반, 의미 부여 가능 | 보통 |
| **인쇄 품질** | ✅ 고해상도 인쇄 완벽 | 해상도(DPI)에 제한 |
| **편집 방법** | 코드·벡터 툴 (Figma, Illustrator) | 픽셀 툴 (Photoshop, GIMP) |
| **소프트웨어 호환성** | 최신 환경에서 완벽 지원 | 모든 환경 지원 |
| **주요 용도** | 로고·아이콘·UI·지도·차트 | 사진·스크린샷·복잡한 UI |

## 파일 크기 실전 비교

같은 로고를 SVG와 PNG로 저장했을 때 파일 크기 차이를 보면 선택 기준이 명확해집니다.

| 이미지 종류 | SVG 크기 | PNG 크기 (72dpi) | PNG 크기 (300dpi) |
|---|---|---|---|
| 단순 원형 아이콘 | ~1 KB | ~8 KB | ~45 KB |
| 회사 로고 (중간 복잡도) | ~12 KB | ~35 KB | ~200 KB |
| 복잡한 일러스트 | ~300 KB | ~150 KB | ~1.2 MB |
| 사진 (1920×1080) | 파일 크기 폭증 | ~1.5 MB | ~8 MB |

**결론:** 단순하고 구조적인 그래픽일수록 SVG가 압도적으로 유리하고, 픽셀이 복잡한 사진·일러스트는 PNG(또는 JPEG)가 현실적입니다.

## 상황별 포맷 선택 가이드

### SVG를 선택해야 할 때

- 회사 로고, 앱 아이콘, 버튼 등 **해상도 독립성이 중요한 UI 요소**
- Retina·4K 디스플레이 등 **다양한 해상도 대응**이 필요할 때
- 웹 애니메이션, 인터랙티브 차트, 지도 같은 **동적 그래픽**
- 현수막·명함·포스터 등 **대형 인쇄물** 제작
- 페이지 로딩 속도를 높여 **Core Web Vitals** 점수를 개선하고 싶을 때

### PNG를 선택해야 할 때

- 인물 사진, 배경이 복잡한 이미지처럼 **픽셀 정보가 풍부한 이미지**
- 레거시 CMS, 오래된 이메일 클라이언트 등 **SVG를 지원하지 않는 환경**
- 스크린샷, UI 목업처럼 **픽셀 정확도**가 중요할 때
- 이미지 합성 시 **반투명 레이어**가 여러 겹 필요한 경우

## PNG → SVG 변환이 필요한 순간

PNG 로고나 아이콘을 가지고 있다면 SVG로 변환하는 것이 장기적으로 훨씬 유리합니다.

- **인쇄·현수막** — 화질 손실 없이 어떤 크기로도 출력 가능
- **웹 성능 최적화** — 파일 크기 감소로 로딩 속도 향상
- **Figma·Illustrator 편집** — 벡터로 변환하면 색상·형태를 자유롭게 수정
- **다크모드 대응** — CSS로 아이콘 색상을 동적으로 변경 가능

### 무료로 변환하는 방법 (3단계)

1. **[imgtosvg.com](https://img-to-svg-six.vercel.app)** 접속 — 설치·회원가입 불필요
2. PNG·JPG·WebP 파일을 드래그 앤 드롭으로 업로드
3. 변환 옵션(배경 제거 등) 선택 후 SVG 즉시 다운로드

**[imgtosvg.com](https://img-to-svg-six.vercel.app)** 은 브라우저에서 바로 동작하는 완전 무료 서비스로, 변환된 SVG를 실시간으로 미리보기한 뒤 다운로드할 수 있습니다.

## 자주 묻는 질문 (FAQ)

### Q1. SVG는 모든 이미지에 쓸 수 있나요?

아니요. SVG는 로고·아이콘·일러스트처럼 **단순하거나 구조적인 그래픽**에 최적입니다. 사진처럼 픽셀 정보가 복잡한 이미지를 SVG로 변환하면 파일 크기가 오히려 폭증하고 렌더링 성능도 저하됩니다. 사진에는 PNG 또는 JPEG를 사용하세요.

### Q2. SVG가 PNG보다 항상 파일 크기가 작나요?

단순한 도형과 로고라면 SVG가 압도적으로 작습니다. 하지만 수천 개의 복잡한 패스로 구성된 일러스트나 사진을 SVG로 저장하면 코드 자체가 방대해져 PNG보다 오히려 커질 수 있습니다. 위 파일 크기 비교표를 참고해 판단하세요.

### Q3. 웹 SEO에서 SVG와 PNG 중 어느 것이 유리한가요?

로고·아이콘에서는 **SVG가 SEO에 유리**합니다. SVG는 `<title>`, `<desc>` 태그로 검색엔진에 의미를 전달할 수 있고, 파일 크기가 작아 Core Web Vitals(LCP·CLS) 점수에 긍정적 영향을 줍니다. 다만 사진 콘텐츠 자체는 PNG/JPEG + alt 태그 조합이 여전히 표준입니다.

### Q4. SVG 파일을 지원하지 않는 환경이 있나요?

네. 오래된 Outlook 이메일 클라이언트, 일부 CMS 업로더, 레거시 오피스 소프트웨어는 SVG를 제대로 지원하지 않습니다. 이런 환경에서는 PNG를 병행하거나, SVG를 PNG로 익스포트해 제출하는 것이 안전합니다.

### Q5. PNG를 SVG로 변환하면 화질이 좋아지나요?

원본 PNG의 해상도 정보가 SVG의 수학적 경로로 변환되므로, **구조적인 로고나 아이콘은 확대해도 선명하게** 표시됩니다. 단, 사진처럼 복잡한 픽셀 정보는 벡터화 과정에서 단순화될 수 있어 세밀한 질감 표현에는 한계가 있습니다.

### Q6. PNG SVG 변환은 무료로 할 수 있나요?

네. **[imgtosvg.com](https://img-to-svg-six.vercel.app)** 에서 회원가입 없이 완전 무료로 변환할 수 있습니다. PNG·JPG·WebP를 업로드하면 수초 내에 SVG로 변환되며, 배경 제거 기능도 함께 제공합니다.
