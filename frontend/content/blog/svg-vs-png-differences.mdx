## SVG vs PNG — 2026년에도 헷갈리는 포맷 선택, 이 글 하나로 끝내기

디자이너든 개발자든 "이 이미지, SVG로 써야 해? PNG로 써야 해?" 라는 질문은 끊임없이 돌아옵니다. 두 포맷은 저장 방식 자체가 달라서, 잘못 선택하면 화질 손상·파일 용량 폭증·SEO 불이익까지 생길 수 있습니다. 이 글에서 두 포맷을 철저하게 비교하고, 상황별 최선의 선택을 명확히 알려드립니다.

---

## SVG란 무엇인가?

**SVG(Scalable Vector Graphics)** 는 XML 코드로 이미지를 표현하는 **벡터 포맷**입니다. 픽셀 대신 수학적 좌표와 경로로 도형을 저장하기 때문에, 4K 모니터든 스마트워치든 **언제나 선명하게** 표시됩니다.

### SVG의 대표 장점

- **무한 확대 가능** — 해상도 걱정 없음
- **파일 크기 작음** — 단순 도형은 KB 단위
- **코드로 편집 가능** — 텍스트 에디터·Figma·Illustrator 모두 지원
- **CSS/JS 애니메이션** — 인터랙티브 웹 그래픽 구현 가능
- **SEO 친화적** — 텍스트 기반 코드라 검색엔진이 내용 파악 가능

---

## PNG란 무엇인가?

**PNG(Portable Network Graphics)** 는 픽셀 단위로 색상 정보를 저장하는 **래스터 포맷**입니다. 무손실 압축과 투명 배경(알파 채널)을 지원해 UI 요소·스크린샷·복잡한 사진에 널리 쓰입니다.

### PNG의 대표 장점

- **투명 배경(알파 채널)** 완벽 지원
- **모든 색상 표현** 가능 — 사진, 복잡한 그라데이션
- **범용 호환성** — 어느 소프트웨어에서나 열림
- **무손실 압축** — JPEG와 달리 화질 손실 없음

## SVG vs PNG 핵심 비교표

| 비교 항목 | SVG | PNG |
|---|---|---|
| 이미지 방식 | 벡터 (수식·경로 기반) | 래스터 (픽셀 기반) |
| 해상도 독립성 | ✅ 무한 확대 선명 | ❌ 확대 시 픽셀 깨짐 |
| 투명 배경 | ✅ 지원 | ✅ 지원 |
| 파일 크기 | 단순 도형 → 매우 작음 | 해상도·색상수에 비례 |
| 애니메이션 | ✅ CSS/JS로 가능 | ❌ 불가 |
| 사진 표현력 | ❌ 부적합 | ✅ 우수 |
| 웹 브라우저 지원 | 모든 최신 브라우저 | 모든 브라우저 |
| SEO 영향 | ✅ 파일 크기 작고 텍스트 인식 | 보통 |
| 편집 방법 | 코드 / 벡터 툴 | 픽셀 편집 툴 필요 |
| 주요 용도 | 로고·아이콘·UI·일러스트 | 사진·스크린샷·UI 이미지 |

## 상황별 포맷 선택 가이드

### SVG를 선택해야 할 때

- 회사 로고, 앱 아이콘, 버튼 등 **해상도 독립성이 중요한 UI 요소**
- Retina 디스플레이·4K 화면 등 **다양한 해상도 대응**이 필요할 때
- 웹 애니메이션, 인터랙티브 차트, 지도 등 **동적 그래픽**
- 파일 용량을 최소화해 **페이지 로딩 속도**를 높이고 싶을 때

### PNG를 선택해야 할 때

- 사진, 복잡한 그라데이션처럼 **픽셀 정보가 풍부한 이미지**
- 투명 배경이 필요하지만 **벡터화가 어려운 복잡한 그래픽**
- 레거시 시스템이나 **오래된 편집 소프트웨어**와 호환해야 할 때
- 스크린샷, UI 목업처럼 **정확한 픽셀 재현**이 중요할 때

## 자주 묻는 질문 (FAQ)

### Q1. SVG는 모든 이미지에 쓸 수 있나요?

아니요. SVG는 로고·아이콘·일러스트처럼 **단순하거나 구조적인 그래픽**에 최적입니다. 사진처럼 수백만 픽셀로 구성된 이미지는 PNG나 JPEG가 훨씬 적합합니다. 무리하게 사진을 SVG로 변환하면 파일 용량이 오히려 폭증할 수 있습니다.

### Q2. SVG가 PNG보다 항상 파일 크기가 작나요?

단순한 도형·로고라면 SVG가 압도적으로 작습니다. 하지만 복잡한 패스가 수천 개인 일러스트는 SVG 코드 자체가 무거워질 수 있으므로, 복잡도에 따라 상황이 달라집니다.

### Q3. 웹 SEO에서 SVG와 PNG 중 어느 것이 유리한가요?

로고·아이콘에서는 **SVG가 SEO에 유리**합니다. SVG는 텍스트 기반 코드라 `<title>`, `<desc>` 태그로 의미를 부여할 수 있고, 파일 크기가 작아 Core Web Vitals(페이지 속도) 점수에도 긍정적 영향을 줍니다.

### Q4. SVG 파일을 지원하지 않는 툴이 있나요?

오래된 이메일 클라이언트(Outlook 일부 버전), 일부 CMS 업로더, 레거시 오피스 소프트웨어는 SVG를 지원하지 않을 수 있습니다. 이런 환경에서는 PNG를 병행해 사용하는 것이 안전합니다.
