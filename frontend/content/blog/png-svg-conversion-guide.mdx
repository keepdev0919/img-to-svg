## PNG와 SVG란 무엇인가?

디지털 이미지 작업을 하다 보면 PNG와 SVG라는 두 형식을 자주 접하게 됩니다. 언뜻 비슷해 보이지만, 이 두 형식은 이미지를 저장하는 방식 자체가 근본적으로 다릅니다.

- **PNG (Portable Network Graphics):** 픽셀(화소)의 집합으로 이미지를 저장합니다. 확대할수록 계단 현상이 생기며 해상도가 고정됩니다.
- **SVG (Scalable Vector Graphics):** 수학적 공식(점·선·곡선)으로 이미지를 표현합니다. 어떤 크기로 확대해도 선명함을 유지합니다.

### PNG vs SVG 핵심 비교

| 항목 | PNG | SVG |
|------|-----|-----|
| 저장 방식 | 픽셀 기반 | 벡터(수식) 기반 |
| 확대 품질 | 깨짐 발생 | 항상 선명 |
| 파일 크기 | 상대적으로 큼 | 단순 이미지는 작음 |
| 투명 배경 | 지원 | 지원 |
| 피그마 편집 | 불가 (이미지 취급) | 가능 (개별 요소 편집) |
| 인쇄 품질 | 해상도 의존 | 무한 해상도 |
| 웹 애니메이션 | 불가 | CSS/JS로 가능 |

**결론:** 로고, 아이콘, 일러스트는 SVG가 압도적으로 유리합니다. 사진처럼 복잡한 이미지는 PNG가 적합합니다.

## PNG를 SVG로 변환해야 하는 대표적인 상황

다음과 같은 상황이라면 PNG → SVG 변환이 필수입니다.

### 디자인 작업
- **피그마(Figma)에서 로고 편집** — 클라이언트에게 PNG로 받은 로고를 색상·크기 수정해야 할 때
- **일러스트레이터 작업** — 아이콘을 벡터로 만들어 자유롭게 변형할 때

### 문서·발표 자료
- **PPT/키노트** — 배경 없는 투명 로고를 고해상도로 삽입할 때
- **Word·노션 문서** — 다양한 배경 위에 로고를 올릴 때

### 웹·앱 개발
- **레티나 디스플레이 대응** — 2배, 3배 해상도에서도 선명한 아이콘
- **CSS 애니메이션** — SVG는 CSS로 색상·모양 변화 애니메이션 구현 가능

### 인쇄·굿즈 제작
- **명함, 현수막, 스티커** — 대형 출력에서도 품질 손실 없음

## 무료 온라인으로 PNG를 SVG로 변환하는 방법

### 필요한 것
- PNG, JPG, 또는 WebP 이미지 파일 (최대 10MB)
- 인터넷이 연결된 브라우저 (프로그램 설치 불필요)

### 단계별 가이드

**① [imgtosvg](https://img-to-svg-six.vercel.app) 접속**

별도의 회원가입이나 로그인 없이 바로 사용할 수 있습니다.

**② 이미지 업로드**

드래그앤드롭으로 파일을 올리거나, 클릭하여 파일 선택 창을 엽니다. PNG, JPG, WebP 모두 지원합니다.

**③ 변환 옵션 조정 (선택)**

| 옵션 | 설명 | 추천 설정 |
|------|------|-----------|
| 색상 정밀도 | 높을수록 색이 다양하게 표현됨 | 로고: 3~4 / 사진: 7~8 |
| 잡음 제거 | 높을수록 작은 노이즈 무시 | 로고: 높게 / 디테일 필요: 낮게 |
| 배경 제거 | AI로 배경 자동 투명 처리 | 로고·아이콘: 체크 권장 |

**④ "SVG로 변환" 클릭**

수 초 내에 변환이 완료됩니다. 파일 복잡도에 따라 최대 30초 소요될 수 있습니다.

**⑤ 다운로드**

"SVG 다운로드" 버튼을 눌러 저장합니다. 업로드한 파일은 변환 직후 서버에서 즉시 삭제되어 개인정보가 보호됩니다.

## 변환 품질을 높이는 실전 팁

### 이미지 유형별 최적 설정

**로고 / 아이콘 (단순한 이미지)**
- 색상 정밀도 낮게 (3~4)
- 잡음 제거 높게
- 배경 제거 옵션 활성화
- 결과: 깔끔한 선, 작은 파일 크기

**복잡한 일러스트**
- 색상 정밀도 중간 (5~6)
- 잡음 제거 중간
- 결과: 원본과 가까운 색상 표현

**사진 (복잡한 이미지)**
- SVG 변환보다 WebP/PNG 유지 권장
- 꼭 SVG로 변환해야 한다면 색상 정밀도 최대로 설정

### 입력 이미지 준비 팁
1. 배경이 단색(흰색 등)이면 배경 제거가 더 정확하게 됩니다
2. 해상도가 높을수록 변환 품질이 좋습니다 (최소 300×300px 권장)
3. 이미지 대비가 뚜렷할수록 선이 선명하게 나옵니다

## 변환 후 활용법

### 피그마에서 SVG 편집하기
1. 피그마 캔버스에 `.svg` 파일을 드래그앤드롭
2. 불러온 오브젝트를 더블클릭 → 내부 패스(path) 선택 가능
3. 색상, 크기, 모양을 자유롭게 수정

### 파워포인트에 SVG 삽입하기
1. 삽입 탭 → 그림 → 이 디바이스
2. `.svg` 파일 선택 후 삽입
3. 마우스 오른쪽 → "그림으로 변환" 없이도 고해상도로 사용 가능

### 웹사이트에 SVG 넣기
```html
<!-- img 태그 사용 -->
<img src="logo.svg" alt="로고" width="200">

<!-- 인라인 SVG (CSS로 색상 변경 가능) -->
<svg>...</svg>
```

## 자주 묻는 질문 (FAQ)

**Q1. PNG SVG 변환은 완전 무료인가요?**

네, [imgtosvg](https://img-to-svg-six.vercel.app)는 회원가입·로그인 없이 완전 무료로 사용할 수 있습니다. 변환 횟수 제한도 없습니다.

**Q2. JPG, WebP 파일도 변환할 수 있나요?**

네, PNG뿐만 아니라 JPG(JPEG)와 WebP 형식도 지원합니다. 업로드 방법과 변환 과정은 동일합니다.

**Q3. 변환한 SVG가 피그마에서 편집이 안 돼요.**

SVG 파일을 피그마에 불러온 뒤 더블클릭을 해보세요. 단순한 로고·아이콘은 개별 패스가 분리되어 편집 가능합니다. 복잡한 이미지는 단일 패스로 뭉쳐질 수 있습니다.

**Q4. 변환된 SVG 파일이 원본보다 너무 크게 나와요.**

복잡한 이미지를 SVG로 변환하면 수많은 패스 데이터가 생성되어 파일이 커집니다. 이런 경우 SVGOMG(온라인 무료)로 SVG를 최적화하면 파일 크기를 줄일 수 있습니다.

**Q5. 업로드한 이미지 파일은 어떻게 관리되나요?**

모든 업로드 파일은 변환 완료 직후 서버에서 자동으로 삭제됩니다. 파일이 서버에 저장·보관되지 않으므로 개인정보와 보안이 보호됩니다.
