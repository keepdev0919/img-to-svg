## PNG와 SVG — 근본적으로 다른 두 가지 형식

PNG와 SVG는 이미지를 저장하는 방식 자체가 다릅니다. PNG는 수백만 개의 **픽셀**을 격자로 기록하고, SVG는 **수학적 경로(path)**로 도형을 표현합니다. 이 차이 하나가 활용 범위와 품질을 완전히 바꿔놓습니다.

### PNG vs SVG 핵심 비교

| 항목 | PNG | SVG |
|------|-----|-----|
| 저장 방식 | 픽셀 기반 (래스터) | 벡터(수식) 기반 |
| 무한 확대 | ❌ 계단 현상 발생 | ✅ 항상 선명 |
| 파일 크기 | 해상도에 비례하여 증가 | 단순 이미지는 매우 작음 |
| 투명 배경 | 지원 | 지원 |
| 피그마 패스 편집 | ❌ 이미지 오브젝트로만 취급 | ✅ 개별 패스 수정 가능 |
| 대형 인쇄 품질 | 해상도 의존 | 무한 해상도 |
| CSS·JS 애니메이션 | ❌ | ✅ |
| 웹 SEO 텍스트 인식 | ❌ | ✅ (텍스트 포함 시) |
| 브라우저 지원 | 모든 브라우저 | 모든 최신 브라우저 |

**결론:** 로고, 아이콘, 일러스트처럼 선이 뚜렷한 그래픽은 SVG가 압도적으로 유리합니다. 사진이나 복잡한 이미지는 PNG를 유지하는 편이 낫습니다.

## PNG를 SVG로 변환해야 하는 핵심 상황 5가지

### 1. 피그마에서 로고·아이콘 편집할 때
클라이언트에게 PNG 로고를 받았다면, SVG로 변환하는 것이 첫 번째 단계입니다. SVG 상태에서는 피그마에서 색상·크기·모양을 자유롭게 수정할 수 있습니다. PNG는 이미지 오브젝트로만 취급되지만, SVG는 각 패스를 분리해 개별 편집할 수 있습니다.

### 2. PPT·키노트에서 화질 유지
PNG를 슬라이드에 삽입하면 확대 시 화질이 흐려집니다. SVG를 사용하면 어떤 화면 크기나 프로젝터 해상도에서도 선명함을 유지합니다.

### 3. 웹·앱의 레티나 디스플레이 대응
4K·레티나 디스플레이에서 PNG 아이콘은 흐리게 보일 수 있습니다. SVG는 CSS 한 줄로 크기를 자유롭게 조절하면서 선명도가 유지됩니다. 단순한 아이콘·로고는 SVG가 PNG보다 파일 크기도 작은 경우가 많습니다.

### 4. 명함·현수막 등 대형 인쇄물 제작
인쇄소는 벡터 파일을 요구하는 경우가 많습니다. PNG를 SVG로 변환하면 수십 미터 크기로 인쇄해도 품질이 전혀 손상되지 않습니다.

### 5. 브랜드 로고 통합 관리
로고를 SVG로 통일해서 관리하면 다크모드 대응, 컬러 변형, 사이즈 조정이 훨씬 쉬워집니다. CSS 변수 하나로 색상을 일괄 변경할 수 있어 브랜드 일관성 유지에도 효과적입니다.

### Step 4 — 변환 및 다운로드
"SVG로 변환" 버튼을 누르면 수 초 안에 결과물이 생성됩니다. "SVG 다운로드" 버튼으로 저장하면 완료입니다. 업로드된 파일은 변환 완료 즉시 서버에서 자동 삭제되어 개인정보가 안전하게 보호됩니다.

## 변환한 SVG 활용 방법

### 피그마에서 편집하기
1. `.svg` 파일을 피그마 캔버스에 드래그앤드롭
2. 불러온 오브젝트를 더블클릭해 내부 패스 선택
3. 색상, 크기, 모양을 자유롭게 수정
4. 컴포넌트로 등록해 여러 페이지에 일관 적용

### 파워포인트에 삽입하기
1. 삽입 탭 → 그림 → 이 디바이스
2. `.svg` 파일 선택 후 삽입
3. 슬라이드를 어떤 크기로 확대해도 선명하게 유지
4. Windows 버전에서는 SVG 내부 요소를 개별 편집 가능

### 웹 코드에서 사용하기

```html
<!-- img 태그 방식 (간단한 삽입) -->
<img src="logo.svg" alt="회사 로고" width="200">

<!-- 인라인 SVG (CSS로 색상·크기 제어 가능) -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <!-- 경로 데이터 -->
</svg>

<!-- CSS 배경 이미지 방식 -->
<style>
  .icon { background-image: url('icon.svg'); background-size: contain; }
</style>
```

## 자주 묻는 질문 (FAQ)

**Q1. PNG를 SVG로 변환하면 화질이 손상되나요?**

아니요. SVG는 벡터 방식이라 원본 이미지를 기반으로 경로를 재생성합니다. 단순한 로고나 아이콘은 원본보다 오히려 더 선명해지는 경우도 있습니다. 다만 복잡한 사진은 세부 표현이 단순화될 수 있으므로, 로고·아이콘·일러스트 용도에 가장 적합합니다.

**Q2. imgtosvg는 완전 무료인가요?**

네, [imgtosvg](https://img-to-svg-six.vercel.app)는 회원가입·로그인 없이 무제한 무료로 사용할 수 있습니다. AI 배경 제거 기능까지 기본 포함되어 있으며, 변환 횟수 제한도 없습니다.

**Q3. JPG, WebP도 SVG로 변환할 수 있나요?**

네, PNG 외에도 JPG(JPEG)와 WebP 형식을 모두 지원합니다. 업로드 방법과 변환 과정은 동일하며, WebP로 저장된 로고·아이콘도 문제없이 변환됩니다.

**Q4. 변환된 SVG가 피그마에서 편집이 안 됩니다.**

파일을 피그마에 불러온 뒤 오브젝트를 더블클릭해보세요. 단순한 로고·아이콘은 개별 패스가 분리되어 편집 가능합니다. 이미지가 너무 복잡하면 단일 패스로 뭉쳐질 수 있는데, 이 경우 색상 정밀도를 낮추고 다시 변환하면 패스 분리가 잘 됩니다.

**Q5. 변환 품질이 기대보다 낮습니다. 어떻게 개선하나요?**

입력 이미지의 해상도를 높이거나 배경을 단색으로 단순화한 뒤 다시 시도해보세요. '잡음 제거' 옵션을 낮추면 세밀한 선이 더 잘 살아나며, 이미지의 명암 대비가 뚜렷할수록 결과물 품질이 크게 향상됩니다.
