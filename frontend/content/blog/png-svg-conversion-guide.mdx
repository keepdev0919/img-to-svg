## PNG와 SVG, 무엇이 다른가?

PNG와 SVG는 디지털 이미지를 저장하는 방식이 근본적으로 다릅니다. PNG는 화소(픽셀)의 집합으로 이미지를 기록하고, SVG는 수학적 경로(path)로 도형을 표현합니다. 이 차이 하나가 활용 범위에 큰 영향을 미칩니다.

### PNG vs SVG 한눈에 비교

| 항목 | PNG | SVG |
|------|-----|-----|
| 저장 방식 | 픽셀 기반 | 벡터(수식) 기반 |
| 무한 확대 | ❌ 계단 현상 발생 | ✅ 항상 선명 |
| 파일 크기 | 해상도에 비례 | 단순 이미지는 매우 작음 |
| 투명 배경 | 지원 | 지원 |
| 피그마 경로 편집 | ❌ (이미지로 취급) | ✅ (개별 패스 편집) |
| 인쇄·대형 출력 | 해상도 의존 | 무한 해상도 |
| CSS·JS 애니메이션 | ❌ | ✅ |
| 브라우저 지원 | 모든 브라우저 | 모든 최신 브라우저 |

**핵심 결론:** 로고, 아이콘, 일러스트처럼 선이 뚜렷한 그래픽은 SVG가 압도적으로 유리합니다. 풍경 사진처럼 색상이 복잡한 이미지는 PNG를 유지하는 것이 좋습니다.

## PNG를 SVG로 꼭 변환해야 하는 4가지 상황

### 1. 피그마에서 로고·아이콘 편집
클라이언트에게 PNG 로고를 받았을 때, SVG로 변환하면 피그마에서 색상·크기·모양을 자유롭게 수정할 수 있습니다.

### 2. PPT·키노트에 고화질 로고 삽입
PNG를 슬라이드에 넣으면 확대 시 화질이 흐려집니다. SVG를 삽입하면 어떤 화면 크기에서도 선명합니다.

### 3. 웹·앱 개발의 레티나 디스플레이 대응
4K·레티나 디스플레이에서도 PNG는 흐려 보일 수 있습니다. SVG는 CSS 한 줄로 크기를 자유롭게 조절하면서도 선명도가 유지됩니다.

### 4. 명함·현수막 등 대형 인쇄물 제작
인쇄소에서 벡터 파일을 요구하는 경우가 많습니다. PNG를 SVG로 변환하면 수십 미터 크기로 인쇄해도 품질이 깨지지 않습니다.

## 변환한 SVG 활용하기

### 피그마에서 편집
1. `.svg` 파일을 피그마 캔버스에 드래그앤드롭
2. 불러온 오브젝트를 더블클릭하면 내부 패스 선택 가능
3. 색상, 크기, 모양을 자유롭게 수정

### 파워포인트에 삽입
1. 삽입 탭 → 그림 → 이 디바이스
2. `.svg` 파일 선택 후 삽입
3. 슬라이드를 어떤 크기로 확대해도 선명하게 유지

### 웹 코드에서 사용

```html
<!-- img 태그 방식 -->
<img src="logo.svg" alt="로고" width="200">

<!-- 인라인 SVG (CSS로 색상·크기 제어 가능) -->
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <!-- 경로 데이터 -->
</svg>
```

## 자주 묻는 질문 (FAQ)

**Q1. PNG를 SVG로 변환하면 화질이 손상되나요?**

아니요. SVG는 벡터 방식이라 원본 이미지를 기반으로 경로를 재생성합니다. 단순한 로고나 아이콘은 원본보다 오히려 선명해지는 경우도 있습니다. 복잡한 사진은 세부 표현이 단순화될 수 있습니다.

**Q2. imgtosvg는 완전 무료인가요?**

네, [imgtosvg](https://img-to-svg-six.vercel.app)는 회원가입·로그인 없이 무제한 무료로 사용할 수 있습니다. 광고 없이 배경 제거 AI 기능까지 포함되어 있습니다.

**Q3. JPG, WebP도 변환할 수 있나요?**

네, PNG 외에도 JPG(JPEG)와 WebP 형식을 지원합니다. 업로드 방법과 변환 과정은 동일합니다.

**Q4. 변환된 SVG가 피그마에서 편집이 안 됩니다.**

파일을 피그마에 불러온 뒤 오브젝트를 더블클릭해보세요. 단순한 로고·아이콘은 개별 패스가 분리되어 편집 가능합니다. 이미지가 너무 복잡하면 단일 패스로 뭉쳐질 수 있으며, 이 경우 색상 정밀도를 낮추고 다시 변환하면 분리가 더 잘 됩니다.

**Q5. 업로드한 파일은 어떻게 관리되나요?**

모든 업로드 파일은 변환 완료 즉시 서버에서 자동 삭제됩니다. 파일이 저장·보관되지 않으므로 개인정보와 보안이 철저히 보호됩니다.
