## 아이콘을 SVG로 변환해야 하는 이유

앱이나 웹 프로젝트를 개발하다 보면 PNG나 WebP 형식으로만 존재하는 아이콘을 SVG로 바꿔야 할 상황이 자주 생깁니다.  
SVG(Scalable Vector Graphics)는 픽셀이 아닌 수식으로 이미지를 표현하기 때문에 어떤 크기에서도 선명하게 보이고, 파일 크기도 훨씬 작습니다.

---

## PNG·WebP 아이콘 vs SVG 아이콘 비교

| 항목 | PNG / WebP 아이콘 | SVG 아이콘 |
|---|---|---|
| 확대 시 품질 | 픽셀이 깨짐 | 항상 선명 |
| 파일 크기 | 크기에 따라 커질 수 있음 | 보통 매우 작음 |
| CSS/JS로 스타일 변경 | 불가능 | 색상·크기 자유롭게 변경 가능 |
| 애니메이션 | 별도 GIF 필요 | CSS·SMIL로 직접 구현 가능 |
| 브라우저 지원 | 모든 브라우저 | 모든 현대 브라우저 |
| 검색엔진 색인 | 불가 | 텍스트처럼 색인 가능 |

## 아이콘 SVG 변환 단계별 가이드

### 1단계 — 변환 사이트 접속

[imgtosvg](https://img-to-svg-six.vercel.app)에 접속합니다.  
별도 설치나 회원가입 없이 무료로 사용할 수 있습니다.

### 2단계 — 아이콘 파일 업로드

PNG, JPG, WebP 형식의 아이콘 파일을 드래그 앤 드롭하거나 파일 선택 버튼으로 업로드합니다.  
배경이 투명한 PNG 아이콘을 사용하면 더욱 깔끔한 SVG 결과물을 얻을 수 있습니다.

### 3단계 — 변환 옵션 조정

- **색상 수(Color Count):** 단색 아이콘은 낮게, 다채로운 아이콘은 높게 설정합니다.  
- **배경 제거:** 불필요한 흰색 또는 단색 배경을 자동으로 제거할 수 있습니다.  
- **경로 단순화:** 세밀도를 조절해 파일 크기를 최적화합니다.

### 4단계 — SVG 다운로드 및 활용

변환된 SVG 파일을 다운로드한 뒤 Figma, VS Code, HTML `<img>` 태그, CSS `background-image` 등 어디서나 사용하세요.

## 자주 묻는 질문 (FAQ)

### Q1. 무료로 아이콘을 SVG로 변환할 수 있나요?
네, [imgtosvg](https://img-to-svg-six.vercel.app)는 완전 무료입니다. 별도 가입이나 결제 없이 바로 사용할 수 있습니다.

### Q2. 변환된 SVG 아이콘의 색상을 바꿀 수 있나요?
SVG 파일은 텍스트 기반이므로 코드 편집기나 Figma에서 `fill` 속성만 수정하면 색상을 자유롭게 바꿀 수 있습니다.

### Q3. 아이콘 배경을 자동으로 제거해주나요?
네, imgtosvg의 배경 제거 옵션을 활성화하면 단색 배경을 자동으로 제거하고 투명 SVG를 생성합니다.

### Q4. 변환 후 SVG 파일이 너무 복잡하게 나옵니다. 어떻게 해야 하나요?
색상 수를 줄이거나 경로 단순화 수준을 높이면 더 간결한 SVG를 얻을 수 있습니다. 또한 Figma나 Inkscape에서 후처리로 불필요한 패스를 정리할 수 있습니다.

### Q5. SVG 아이콘을 HTML에 삽입하는 가장 좋은 방법은 무엇인가요?
`<img src="icon.svg">` 태그로 삽입하거나, SVG 코드를 HTML에 직접 인라인으로 넣으면 CSS로 색상을 동적으로 제어할 수 있어 더욱 유연합니다.
