## 아이콘은 왜 SVG여야 할까?

Retina 디스플레이와 4K 모니터가 보급된 지금, PNG·WebP 아이콘을 확대하면 픽셀이 뭉개지는 문제는 더 이상 용납되지 않습니다. SVG(Scalable Vector Graphics)는 수학적 경로(Path)로 이미지를 정의하기 때문에 어떤 해상도에서도 완벽하게 선명하고, CSS와 JavaScript로 색상과 크기를 동적으로 제어할 수 있습니다.

2026년 현재 GitHub, Google, Apple 등 대부분의 대형 서비스가 UI 아이콘 전체를 SVG로 전환 완료했습니다. 지금이 바로 PNG 아이콘을 SVG로 바꿀 최적의 시점입니다.

## PNG·WebP 아이콘 vs SVG 아이콘 — 핵심 비교

| 항목 | PNG / WebP 아이콘 | SVG 아이콘 |
|---|---|---|
| 해상도 독립성 | ❌ 확대 시 픽셀 깨짐 | ✅ 무한 확대 선명 |
| 파일 크기 | 해상도에 비례해 증가 | 보통 수 KB 이하 |
| 다크 모드 대응 | 별도 이미지 필요 | CSS `fill`로 즉시 변경 |
| CSS 스타일링 | 불가능 | 색상·그림자·애니메이션 자유롭게 |
| 애니메이션 | GIF·APNG 별도 필요 | CSS·SMIL로 직접 구현 |
| SEO·접근성 | alt 텍스트만 가능 | `<title>` · `<desc>` 태그 완전 지원 |
| 브라우저 지원 | 모든 브라우저 | 모든 현대 브라우저 (IE11 제외) |

## 아이콘 SVG 변환 — 단계별 실전 가이드

### 1단계 — imgtosvg 접속

[imgtosvg](https://img-to-svg-six.vercel.app)에 접속합니다. 설치나 회원가입 없이 완전 무료로 이용 가능합니다.

### 2단계 — 아이콘 파일 업로드

PNG, JPG, WebP 형식을 드래그 앤 드롭하거나 파일 선택으로 업로드합니다.

> **팁:** 배경이 투명한 PNG 아이콘을 사용하면 가장 깔끔한 SVG 결과물을 얻을 수 있습니다. 단색 배경이라면 배경 제거 옵션을 활성화하세요.

### 3단계 — 변환 옵션 최적화

| 옵션 | 권장 설정 | 효과 |
|---|---|---|
| 색상 수 | 단색 아이콘: 2~4 / 다채로운 아이콘: 8~16 | 파일 크기와 품질의 균형 |
| 배경 제거 | 단색 배경일 때 활성화 | 투명 SVG 생성 |
| 경로 단순화 | 중간~높음 | 불필요한 노드 제거로 경량화 |
| 필터 스팩크 | 낮게 유지 | 노이즈 픽셀 무시 |

### 4단계 — SVG 다운로드 및 활용

변환된 SVG를 다운로드한 뒤 아래 방법으로 바로 사용할 수 있습니다.

- **HTML 삽입:** `<img src="icon.svg" alt="아이콘">` 또는 인라인 `<svg>` 태그
- **Figma 불러오기:** 파일 → 가져오기(Import) → SVG 선택
- **React 컴포넌트:** SVGR로 SVG를 JSX 컴포넌트로 변환
- **CSS 배경:** `background-image: url('icon.svg')`

## 아이콘 유형별 변환 전략

### 단색 라인 아이콘

머티리얼·페더·루사이드 같은 선형 아이콘은 **색상 수를 2로** 설정하면 깔끔한 결과를 얻습니다. 변환 후 `fill` 또는 `stroke` 값을 `currentColor`로 바꾸면 CSS 변수로 색상을 자유롭게 제어할 수 있습니다.

### 컬러 일러스트 아이콘

이모지 스타일이나 다색 일러스트 아이콘은 **색상 수를 12~24**로 높이고, 경로 단순화는 낮게 설정해 세부 표현을 유지하세요. 변환 후 SVGO(svgomg.net)로 추가 압축을 권장합니다.

### 로고·브랜드 아이콘

정확한 색상 재현이 중요한 경우, 원본 이미지 해상도를 **512×512 px 이상**으로 준비하고 색상 수를 원본 팔레트에 맞게 조정하세요.

## 자주 묻는 질문 (FAQ)

### Q1. 아이콘 SVG 변환은 정말 무료인가요?

네, [imgtosvg](https://img-to-svg-six.vercel.app)는 완전 무료입니다. 계정 생성이나 결제 없이 PNG·JPG·WebP 아이콘을 즉시 SVG로 변환할 수 있으며, 변환 횟수 제한도 없습니다.

### Q2. 변환된 SVG 아이콘의 색상을 어떻게 바꾸나요?

SVG는 텍스트 기반 파일이므로 코드 편집기에서 `fill="#000000"` 부분을 원하는 색상 코드로 수정하면 됩니다. Figma나 Inkscape에서 GUI로 변경하는 것도 가능합니다. 테마 시스템과 연동하려면 `fill="currentColor"`로 바꿔 CSS 변수로 제어하세요.

### Q3. 배경 제거 기능은 어떻게 작동하나요?

imgtosvg의 배경 제거 기능은 rembg AI 모델을 활용해 아이콘 주변 단색 배경을 자동으로 감지하고 투명 처리합니다. 복잡한 배경도 아이콘 실루엣만 깔끔하게 추출할 수 있습니다.

### Q4. 변환 후 SVG 파일 크기가 너무 크다면?

색상 수를 줄이거나 경로 단순화 수준을 높이세요. 추가로 SVGO를 사용하면 평균 40~70%까지 압축이 가능합니다. 불필요한 `<title>`, `<desc>`, `id` 속성 제거도 효과적입니다.

### Q5. SVG 아이콘을 React에서 가장 잘 쓰는 방법은?

`@svgr/webpack` 또는 Next.js 내장 SVGR 지원을 통해 SVG를 React 컴포넌트로 import할 수 있습니다. `<Icon width={24} height={24} fill="currentColor" />` 형태로 props를 활용하면 디자인 시스템 구축에 매우 편리합니다.
