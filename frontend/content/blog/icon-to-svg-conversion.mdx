## 왜 아이콘은 SVG여야 하는가?

Retina·4K 디스플레이가 표준이 된 2026년, PNG나 WebP 아이콘을 확대하면 픽셀이 뭉개지는 문제는 치명적인 품질 손상입니다. SVG(Scalable Vector Graphics)는 수학적 경로로 이미지를 정의하기 때문에 **어떤 해상도에서도 완벽하게 선명**합니다. 거기에 CSS 변수로 색상을 바꾸고, 애니메이션을 입히고, 파일 크기까지 작아지는 장점이 더해집니다. GitHub·Google·Apple이 UI 아이콘을 전부 SVG로 전환한 데는 이유가 있습니다.

---

## PNG·WebP 아이콘 vs SVG 아이콘 비교

| 항목 | PNG / WebP | SVG |
|---|---|---|
| 해상도 독립성 | ❌ 확대 시 픽셀 깨짐 | ✅ 무한 확대 선명 |
| 파일 크기 | 해상도에 비례 증가 | 보통 수 KB 이하 |
| 다크 모드 대응 | 별도 이미지 필요 | CSS `fill`로 즉시 변경 |
| CSS 스타일링 | 불가 | 색상·크기·애니메이션 자유 |
| 접근성(SEO) | `alt` 텍스트만 | `<title>`, `<desc>` 완전 지원 |
| 인라인 삽입 | 불가 | HTML에 직접 삽입 가능 |
| 애니메이션 | GIF·APNG 별도 필요 | CSS·SMIL로 직접 구현 |

## 5분 안에 완료하는 아이콘 SVG 변환 단계별 가이드

### 1단계 — imgtosvg 접속

[imgtosvg](https://img-to-svg-six.vercel.app)에 접속합니다. 설치, 회원가입, 결제 없이 완전 무료로 이용할 수 있습니다.

### 2단계 — 아이콘 파일 업로드

PNG, JPG, WebP 아이콘 파일을 드래그 앤 드롭하거나 클릭해서 업로드하세요.

> **팁:** 투명 배경 PNG를 사용하면 가장 깔끔한 SVG가 나옵니다. 단색 배경 아이콘이라면 **배경 제거** 옵션을 켜세요.

### 3단계 — 아이콘 유형별 최적 설정 적용

| 아이콘 유형 | 색상 수 권장 | 경로 단순화 | 배경 제거 |
|---|---|---|---|
| 단색 라인 아이콘 | 2~4 | 높음 | 켜기 |
| 컬러 일러스트 아이콘 | 12~24 | 낮음 | 필요 시 켜기 |
| 로고·브랜드 아이콘 | 원본 팔레트 수 | 중간 | 켜기 |
| 픽셀 아트 아이콘 | 4~8 | 낮음 | 끄기 |

### 4단계 — SVG 다운로드 및 프로젝트 적용

변환이 완료되면 SVG 파일을 다운로드하여 바로 활용하세요.

- **HTML 삽입:** `<img src="icon.svg" alt="아이콘">` 또는 인라인 `<svg>` 태그
- **React/Next.js:** SVGR(`@svgr/webpack`)로 컴포넌트 변환 후 `<Icon fill="currentColor" />`
- **Figma:** 파일 → 가져오기(Import) → SVG 선택
- **CSS 배경:** `background-image: url('icon.svg')`

## 아이콘 유형별 심화 변환 전략

### 단색 라인 아이콘 (머티리얼·페더·루사이드 계열)

색상 수를 **2**로 설정하면 불필요한 경로가 사라져 가장 가볍고 깔끔한 SVG를 얻습니다. 변환 후 SVG 코드에서 `fill="#000000"`을 `fill="currentColor"`로 바꾸면 CSS 변수만으로 테마 색상을 제어할 수 있습니다.

### 컬러 이모지·일러스트 아이콘

색상 수를 **12~24**로 높이고 경로 단순화를 낮게 설정해 세부 표현을 보존하세요. 변환 후 [SVGOMG](https://svgomg.net)으로 추가 압축하면 평균 30~50% 파일 크기를 줄일 수 있습니다.

### 로고·브랜드 아이콘

정확한 색상 재현을 위해 원본 이미지를 **512×512 px 이상**으로 준비하고, 색상 수는 브랜드 팔레트에 맞게 조정하세요. 기업 로고는 보통 2~6색이면 충분합니다.

## 변환 품질을 높이는 핵심 팁 3가지

1. **고해상도 원본 사용** — 최소 256×256 px 이상의 이미지를 사용해야 경로가 정밀하게 추출됩니다.
2. **배경 먼저 제거** — 배경이 섞이면 불필요한 경로가 늘어납니다. 배경 제거 옵션을 적극 활용하세요.
3. **SVGO로 후처리** — 변환 후 SVGO를 통해 `viewBox` 정규화, 불필요 메타데이터 제거를 하면 웹 성능이 향상됩니다.

## 자주 묻는 질문 (FAQ)

### Q1. 아이콘 SVG 변환은 정말 무료인가요?

네. [imgtosvg](https://img-to-svg-six.vercel.app)는 가입이나 결제 없이 PNG·JPG·WebP 아이콘을 무제한으로 SVG 변환할 수 있습니다.

### Q2. 변환된 SVG 아이콘의 색상을 바꾸려면?

SVG는 텍스트 파일이라 코드 편집기에서 `fill="#xxxxxx"`를 직접 수정하거나, Figma·Inkscape GUI로 변경할 수 있습니다. 테마 시스템에 연결하려면 `fill="currentColor"`로 교체하고 CSS 변수를 활용하세요.

### Q3. 배경이 흰색인 아이콘도 투명 SVG로 만들 수 있나요?

네. imgtosvg의 **배경 제거** 옵션이 rembg AI 모델을 통해 흰색·단색 배경을 자동으로 감지하고 투명 처리합니다.

### Q4. SVG 파일 크기가 너무 크면 어떻게 하나요?

색상 수를 줄이고 경로 단순화 수준을 높이면 파일이 가벼워집니다. 추가로 SVGO를 사용하면 40~70%까지 압축이 가능합니다.

### Q5. React에서 SVG 아이콘을 컴포넌트로 쓰는 방법은?

`@svgr/webpack`을 설치하고 webpack 설정에 SVGR 로더를 추가하면 `import Icon from './icon.svg'` 형태로 SVG를 React 컴포넌트로 바로 사용할 수 있습니다. Next.js는 `@svgr/webpack` 플러그인을 `next.config.js`에 추가하면 됩니다.
