## 피그마에서 SVG가 필요한 이유

피그마(Figma)는 UI·UX 디자인 협업 플랫폼의 사실상 표준입니다. 여기에 SVG(Scalable Vector Graphics)를 활용하면 해상도 걱정 없이 로고·아이콘·일러스트를 무한 확대·축소할 수 있습니다. 반면 PNG나 JPG는 확대하면 픽셀이 깨지고, 피그마 내에서 색상·형태를 직접 수정하기 어렵습니다.

이 가이드는 **SVG를 피그마로 불러오는 5가지 방법**과, 래스터 이미지를 SVG로 변환해 활용하는 **실전 워크플로**를 처음부터 끝까지 설명합니다.

## 피그마에서 SVG를 불러오는 5가지 방법

### 방법 1 — 드래그 앤 드롭 (가장 빠름)

1. 파일 탐색기(Windows 탐색기 / macOS Finder)에서 `.svg` 파일을 찾습니다.
2. 피그마 캔버스로 직접 드래그합니다.
3. 마우스를 놓으면 벡터 프레임으로 즉시 삽입됩니다.
4. 레이어 패널에서 **Ungroup**을 눌러 개별 패스를 분리합니다.

### 방법 2 — File 메뉴 가져오기

1. 상단 메뉴 **File → Place image…** 클릭합니다.
2. `.svg` 파일을 선택하고 **열기**를 누릅니다.
3. 캔버스를 클릭해 원하는 위치에 삽입합니다.

### 방법 3 — SVG 코드 복사·붙여넣기

텍스트 에디터에서 `<svg>...</svg>` 코드 전체를 복사(`Ctrl+A → Ctrl+C`)한 뒤 피그마 캔버스에 `Ctrl+V`(Mac: `Cmd+V`)로 붙여넣으면 벡터 오브젝트로 자동 변환됩니다. 코드 수정 결과를 빠르게 확인할 때 특히 유용합니다.

### 방법 4 — 피그마 플러그인 활용

**Iconify**, **Material Symbols**, **Feather Icons** 같은 플러그인으로 수천 개의 SVG 아이콘을 검색·삽입할 수 있습니다. **Plugins → Browse plugins in Community**에서 설치합니다.

### 방법 5 — 피그마 Community 파일 직접 열기

Figma Community에서 공유된 파일(.fig)을 열면 SVG 컴포넌트가 포함된 디자인 시스템을 그대로 활용할 수 있습니다. 대규모 아이콘 라이브러리를 팀 프로젝트에 바로 연결할 때 효과적입니다.

> **핵심 팁:** 임포트 후 레이어 패널에서 더블클릭해 **Vector Edit Mode**로 진입하면 개별 앵커 포인트를 자유롭게 수정할 수 있습니다.

## SVG vs 래스터 이미지 — 피그마 편집 비교

| 항목 | SVG (벡터) | PNG / JPG | WebP |
|------|-----------|-----------|------|
| 해상도 손실 | 없음 (무한 확대) | 확대 시 픽셀화 | 확대 시 픽셀화 |
| 레이어 분리 편집 | 패스 단위 가능 | 불가능 | 불가능 |
| 색상·형태 수정 | 피그마 내 직접 수정 | 재제작 필요 | 재제작 필요 |
| 파일 크기 | 단순 도형은 매우 작음 | 해상도에 비례 | PNG보다 소폭 작음 |
| 웹 CSS 애니메이션 | 손쉽게 적용 | 제한적 | 제한적 |
| 피그마 컴포넌트화 | 완벽 호환 | 제한적 | 제한적 |
| 인쇄 품질 | 벡터라 무결점 | DPI 의존 | DPI 의존 |
| 접근성 (title, desc) | 기본 지원 | img 태그 필요 | img 태그 필요 |

**결론:** 로고·아이콘·일러스트는 반드시 SVG로 관리해야 피그마 워크플로 효율이 극대화됩니다.

## PNG·JPG·WebP → SVG 변환 후 피그마에서 활용하기

소스 파일이 래스터 이미지뿐이라면 먼저 SVG로 변환해야 피그마 벡터 편집이 가능합니다. 무료 온라인 도구 **[imgtosvg](https://img-to-svg-six.vercel.app)** 를 사용하면 설치 없이 즉시 변환할 수 있습니다.

### 변환 → 피그마 임포트 전체 워크플로

1. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에 접속합니다.
2. PNG, JPG, 또는 WebP 이미지를 드래그 앤 드롭 또는 파일 선택으로 업로드합니다.
3. **배경 제거** 옵션을 활성화해 흰 배경을 제거합니다.
4. 색상 수, 경로 세밀도 등 변환 옵션을 조정합니다.
5. **변환하기** 버튼을 클릭합니다.
6. 변환된 `.svg` 파일을 다운로드합니다.
7. 피그마 캔버스에 드래그 앤 드롭으로 임포트합니다.
8. **Ungroup**으로 레이어를 분리하면 색상·형태를 자유롭게 편집할 수 있습니다.

### 이미지 유형별 권장 변환 설정

| 이미지 유형 | 권장 색상 수 | 배경 제거 | 이유 |
|------------|------------|---------|------|
| 단색 로고 | 2~4색 | 켜기 | 깔끔한 패스, 작은 파일 |
| 멀티컬러 아이콘 | 8~16색 | 켜기 | 색상 정확도 유지 |
| 일러스트 | 16~32색 | 상황에 따라 | 세밀한 표현 |
| 사진 | 미권장 | — | 벡터화 결과 단순화됨 |

### 변환 품질 향상 팁

- **배경 제거 먼저:** 흰 배경이 있는 로고는 배경 제거 후 변환하면 훨씬 깔끔한 SVG가 생성됩니다.
- **색상 수 최소화:** 단색 로고는 2~4색으로 제한하면 파일 크기가 줄고 피그마 편집도 쉬워집니다.
- **고해상도 원본 사용:** 변환 품질은 입력 이미지 해상도에 비례합니다. 최소 500px 이상을 권장합니다.

## 피그마에서 SVG 편집 핵심 기능

### Vector Edit Mode (패스 편집)
SVG 요소를 더블클릭하면 Vector Edit Mode로 진입합니다. 앵커 포인트를 드래그하거나 삭제해 형태를 자유롭게 수정할 수 있습니다. `Enter` 키로 진입, `Esc` 키로 종료합니다.

### 색상 일괄 변경
**Edit → Select All with Same Fill Color**로 동일 색상 레이어를 한 번에 선택한 뒤 Fill 패널에서 교체하면 모든 인스턴스가 동시에 업데이트됩니다.

### Boolean Operations (패스 연산)
**Union, Subtract, Intersect, Exclude**로 여러 SVG 패스를 합치거나 잘라낼 수 있습니다. 복잡한 도형을 빠르게 제작할 때 필수입니다.

### SVG로 내보내기
완성된 디자인 내보내기: 레이어 선택 → 오른쪽 패널 **Export** → **SVG** 선택 → **Export** 클릭. "Include id attribute" 옵션을 켜면 CSS 스타일링에 유리합니다.

## 자주 묻는 질문 (FAQ)

### Q1. 피그마에 SVG를 불러왔는데 편집이 안 됩니다.
**A.** SVG가 단일 그룹으로 임포트된 경우입니다. 레이어 패널에서 선택 후 **오른쪽 클릭 → Ungroup**을 반복하거나, 더블클릭해 Vector Edit Mode로 진입하세요. 그래도 안 된다면 **Flatten Selection**으로 패스를 병합한 뒤 다시 시도하세요.

### Q2. SVG 파일 크기가 너무 커서 피그마가 느려집니다.
**A.** 경로가 지나치게 복잡한 SVG가 원인입니다. imgtosvg에서 변환 시 **경로 단순화 수준**을 높이거나, 피그마에서 **Flatten Selection**으로 패스를 병합하세요. 숨겨진 불필요한 레이어 삭제도 효과적입니다.

### Q3. PNG 로고를 SVG로 변환하면 품질이 좋은가요?
**A.** 단색 또는 소수 색상의 로고·아이콘은 변환 품질이 매우 우수합니다. 복잡한 그라데이션 사진은 결과가 단순화될 수 있습니다. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에서 무료로 먼저 테스트해 보세요.

### Q4. 피그마 무료 플랜에서도 SVG를 불러올 수 있나요?
**A.** 네, SVG 임포트·익스포트는 피그마 무료 플랜(Starter)에서도 제한 없이 사용 가능합니다. 팀 기능 없이도 SVG 기반 벡터 편집의 모든 기능을 활용할 수 있습니다.

### Q5. WebP 이미지도 SVG로 변환해 피그마에서 사용할 수 있나요?
**A.** 가능합니다. **[imgtosvg](https://img-to-svg-six.vercel.app)** 는 WebP 포맷을 완벽 지원합니다. WebP → SVG 변환 후 피그마에 임포트하면 완전한 벡터 편집이 가능합니다.

### Q6. 피그마에서 SVG를 다른 형식으로 내보낼 수 있나요?
**A.** 피그마는 SVG 외에도 PNG, JPG, PDF, WebP로 내보내기를 지원합니다. Export 패널에서 원하는 포맷을 선택하고, 배율(1x, 2x, 3x)을 지정해 다양한 해상도로 동시 내보내기가 가능합니다.
