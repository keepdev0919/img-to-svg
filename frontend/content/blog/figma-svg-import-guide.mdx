## 피그마에서 SVG 파일을 불러오는 방법

피그마(Figma)는 웹 기반 협업 디자인 툴로, SVG(Scalable Vector Graphics)를 네이티브로 지원합니다. SVG를 임포트하면 개별 패스(path)와 레이어를 자유롭게 편집할 수 있어 UI·그래픽 디자이너 모두에게 필수 기술입니다.

### 방법 1 — 드래그 앤 드롭 (가장 빠름)

1. 파일 탐색기에서 `.svg` 파일을 찾습니다.
2. 피그마 캔버스 위로 직접 드래그합니다.
3. 마우스를 놓으면 SVG가 즉시 프레임으로 삽입됩니다.

### 방법 2 — 메뉴에서 가져오기

1. 피그마 상단 메뉴 **File → Place image…** 를 클릭합니다.
2. 탐색기에서 `.svg` 파일을 선택하고 **열기**를 클릭합니다.
3. 캔버스 위를 클릭하면 SVG가 프레임으로 삽입됩니다.

### 방법 3 — 복사·붙여넣기

SVG 코드를 텍스트 에디터에서 전체 복사한 뒤, 피그마 캔버스에서 `Ctrl+V` / `Cmd+V`로 붙여넣으면 벡터로 직접 변환됩니다. 코드 레벨에서 수정이 필요한 경우 유용합니다.

> **팁:** 삽입 후 레이어 패널에서 **Ungroup** 또는 **Double click → 그룹 해제**를 반복하면 개별 벡터 패스로 분리되어 색상·형태를 자유롭게 수정할 수 있습니다.

## SVG vs 래스터 이미지 — 피그마 편집 비교

| 항목 | SVG (벡터) | PNG / JPG (래스터) |
|------|-----------|------------------|
| 해상도 손실 | 없음 — 무한 확대 가능 | 확대 시 픽셀화 발생 |
| 레이어 분리 편집 | 패스 단위로 가능 | 불가능 |
| 색상·형태 수정 | 피그마 내에서 직접 수정 | 재제작 필요 |
| 파일 크기 | 단순 도형은 매우 작음 | 해상도에 비례해 큼 |
| 애니메이션 | CSS·JS로 손쉽게 적용 | 제한적 |
| 접근성 | `<title>` 태그로 텍스트 대체 가능 | alt 텍스트만 가능 |
| 피그마 컴포넌트 활용 | 완벽 호환 | 제한적 |

결론적으로, 로고·아이콘·일러스트는 SVG 포맷으로 다루는 것이 피그마 작업 효율을 극대화합니다.

## PNG·JPG 이미지를 SVG로 변환한 뒤 피그마에서 활용하기

래스터 이미지(PNG, JPG, WebP)만 보유하고 있다면 먼저 SVG로 변환해야 피그마에서 벡터 편집이 가능합니다. 무료 온라인 도구 **[imgtosvg](https://img-to-svg-six.vercel.app)** 를 사용하면 별도 설치 없이 즉시 변환할 수 있습니다.

### 변환 → 임포트 전체 워크플로

1. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에 접속합니다.
2. PNG, JPG, 또는 WebP 이미지를 업로드합니다 (최대 10MB).
3. 색상 수, 경로 세밀도 등 변환 옵션을 조정합니다.
4. **변환하기** 버튼을 클릭합니다.
5. 생성된 `.svg` 파일을 다운로드합니다.
6. 다운로드한 SVG를 피그마 캔버스에 드래그 앤 드롭합니다.
7. **Ungroup**으로 레이어를 분리하면 색상, 크기, 형태를 자유롭게 편집할 수 있습니다.

### 변환 품질을 높이는 팁

- **배경 제거 후 변환:** 흰 배경이 있는 로고는 imgtosvg의 배경 제거 기능을 먼저 사용하면 훨씬 깔끔한 SVG가 생성됩니다.
- **색상 수 줄이기:** 단색·2색 로고는 색상 수를 2~4개로 제한하면 파일 크기가 줄고 편집이 쉬워집니다.
- **고해상도 원본 사용:** 변환 품질은 입력 이미지 해상도에 비례합니다. 최소 500px 이상의 이미지를 사용하세요.

## 피그마에서 SVG를 편집하는 핵심 기능

### 패스 편집 (벡터 툴)
삽입된 SVG 요소를 더블클릭하면 **Vector Edit Mode**로 진입합니다. 앵커 포인트를 드래그하거나 삭제해 형태를 자유롭게 변경할 수 있습니다.

### 색상 일괄 변경
레이어 패널에서 같은 색상의 레이어를 `Ctrl+클릭`으로 다중 선택한 뒤 Fill 패널에서 색상을 변경하면 한 번에 바꿀 수 있습니다.

### SVG 내보내기
완성된 디자인을 SVG로 다시 내보낼 때는: 내보낼 레이어 선택 → 오른쪽 패널 **Export** → 포맷을 **SVG**로 선택 → **Export** 클릭.

## 자주 묻는 질문 (FAQ)

### Q1. 피그마에 SVG를 불러왔는데 편집이 안 돼요.
**A.** SVG가 단일 그룹으로 임포트된 경우입니다. 레이어 패널에서 해당 요소를 선택 후 **오른쪽 클릭 → Ungroup**을 반복하거나, 요소를 더블클릭해 벡터 편집 모드로 진입해 보세요.

### Q2. SVG 파일 크기가 너무 커서 피그마가 느려요.
**A.** 경로(path)가 지나치게 복잡한 SVG는 성능 저하를 일으킵니다. imgtosvg에서 변환할 때 **경로 단순화 수준**을 높이거나, 피그마 **Flatten Selection** 기능으로 패스를 병합하면 개선됩니다.

### Q3. 피그마에서 SVG를 내보내는 방법은?
**A.** 내보낼 레이어나 프레임 선택 → 오른쪽 패널 하단 **Export** 섹션 → 형식을 **SVG**로 설정 → **Export** 버튼 클릭. Include "id" attribute 옵션을 켜면 CSS 스타일링에 유리합니다.

### Q4. PNG 로고를 SVG로 변환하면 품질이 좋은가요?
**A.** 단색 또는 소수 색상의 로고·아이콘은 변환 품질이 매우 좋습니다. 사진처럼 복잡한 그라데이션 이미지는 벡터화 결과가 단순화될 수 있습니다. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에서 무료로 미리 테스트해 보세요.

### Q5. 피그마 무료 플랜에서도 SVG를 불러올 수 있나요?
**A.** 네, SVG 임포트·익스포트는 무료 플랜(Starter)에서도 제한 없이 사용 가능합니다.

### Q6. WebP 이미지도 SVG로 변환해 피그마에서 쓸 수 있나요?
**A.** 가능합니다. **[imgtosvg](https://img-to-svg-six.vercel.app)** 는 WebP 포맷도 지원하므로, WebP → SVG 변환 후 피그마에 임포트하면 됩니다.
