## 왜 PPT에 SVG를 써야 할까?

발표 자료에 PNG·JPG 이미지를 삽입하면 대형 스크린이나 4K 프로젝터 앞에서 이미지가 뭉개지는 경험, 한 번쯤 해보셨을 겁니다. SVG(Scalable Vector Graphics)는 수학적 경로 기반의 벡터 형식이라 **크기를 아무리 키워도 선명도가 100% 유지**됩니다.

로고, 아이콘, 인포그래픽처럼 단순·명확한 그래픽을 SVG로 바꿔 PPT에 삽입하면 발표 퀄리티가 눈에 띄게 달라집니다. Microsoft 365, PowerPoint 2019 이상, 구글 슬라이드, 애플 키노트 모두 SVG를 공식 지원하므로 이제 벡터 이미지 활용은 선택이 아닌 필수입니다.

## SVG vs PNG vs JPG — PPT 활용 완전 비교

| 항목 | SVG | PNG | JPG |
|------|-----|-----|-----|
| 확대 시 품질 | 완벽히 선명함 | 픽셀 깨짐 | 픽셀 깨짐 + 압축 노이즈 |
| 파일 용량 | 단순 그래픽에서 매우 작음 | 해상도에 따라 큼 | 중간 (손실 압축) |
| PPT 내 색상 편집 | 그룹 해제 후 직접 가능 | 불가 | 불가 |
| 투명 배경 | 기본 지원 | 지원 | 미지원 |
| 애니메이션 적용 | 제한적 지원 (MS365) | 미지원 | 미지원 |
| PDF 내보내기 품질 | 벡터 그대로 유지 | DPI에 의존 | DPI에 의존 |
| 지원 PPT 버전 | 2019 / MS365 이상 | 모든 버전 | 모든 버전 |
| 텍스트 편집기로 수정 | 가능 (코드 직접 편집) | 불가 | 불가 |

## 파워포인트에 SVG 삽입하는 방법 (단계별)

### 1단계: SVG 파일 준비하기

삽입할 SVG 파일이 없다면 PNG·JPG·WebP를 먼저 변환해야 합니다. [imgtosvg](https://img-to-svg-six.vercel.app)에 접속해 파일을 드래그 앤 드롭하면 수 초 만에 SVG로 변환됩니다. 배경 제거 옵션도 지원하므로 투명 배경 SVG를 바로 얻을 수 있습니다.

### 2단계: 슬라이드에 SVG 삽입하기

1. 파워포인트를 열고 삽입할 슬라이드를 선택합니다.
2. 상단 메뉴 **삽입 → 그림 → 이 장치**를 클릭합니다.
3. 파일 탐색기에서 `.svg` 파일을 선택 후 **삽입**을 누릅니다.
4. 슬라이드에 SVG가 배치되면 모서리 핸들을 드래그해 크기를 자유롭게 조절합니다.

> **지원 버전:** Microsoft 365, PowerPoint 2019·2021 이상에서 SVG 공식 지원. PowerPoint 2016은 일부만 지원, 2013 이하는 미지원.

### 3단계: SVG 색상 및 요소 편집하기

SVG의 가장 큰 강점은 PPT 내에서 색상을 직접 바꿀 수 있다는 점입니다.

1. 삽입된 SVG를 마우스 오른쪽 클릭합니다.
2. **그룹 해제 → 예**를 선택합니다.
3. 개별 도형으로 분리된 요소를 클릭해 **채우기 색** 또는 **선 색**을 변경합니다.
4. 편집 완료 후 전체 선택 → **그룹화**로 하나의 오브젝트처럼 관리합니다.

### 4단계: 애니메이션 및 전환 효과 적용하기

Microsoft 365에서는 SVG에도 애니메이션을 적용할 수 있습니다. 삽입된 SVG를 선택한 후 **애니메이션 탭**에서 나타내기·강조·사라지기 효과를 설정하세요. 그룹 해제 후 개별 경로 단위로 애니메이션을 넣으면 훨씬 풍부한 연출이 가능합니다.

## PNG·JPG·WebP → SVG 변환 후 PPT에 활용하기

회사 로고나 아이콘이 PNG 형식밖에 없다면, SVG로 변환 후 PPT에 삽입하면 발표 품질이 크게 향상됩니다.

### imgtosvg로 변환하는 방법

1. [imgtosvg](https://img-to-svg-six.vercel.app) 접속
2. PNG·JPG·WebP 파일 업로드 (드래그 앤 드롭 가능)
3. **변환 시작** 클릭 후 수 초 내 완료
4. SVG 파일 다운로드
5. 위 단계에 따라 파워포인트에 삽입

설치 없이 완전 무료로 사용할 수 있으며, 배경 제거 옵션을 함께 활용하면 어떤 슬라이드 배경과도 자연스럽게 어울리는 투명 SVG를 즉시 얻을 수 있습니다.

## 구글 슬라이드 · 애플 키노트에서 SVG 사용하기

### 구글 슬라이드

2023년 업데이트 이후 SVG 직접 삽입을 공식 지원합니다. **삽입 → 이미지 → 컴퓨터에서 업로드**로 SVG 파일을 불러오면 됩니다. 파워포인트처럼 그룹 해제 후 색상 편집 기능은 아직 제한적이므로, 편집이 필요하다면 먼저 SVG 코드를 수정 후 업로드하는 방법을 권장합니다.

### 애플 키노트

macOS·iOS 환경에서 SVG를 완벽히 지원합니다. **삽입 → 이미지 선택**으로 SVG를 불러오면 고품질로 표시되며, 크기 조절 시에도 선명도가 유지됩니다.

## 자주 발생하는 오류와 해결 방법

### 삽입 후 흰색 배경이 나타나는 경우

변환된 SVG에 배경 레이어가 포함된 것입니다. [imgtosvg](https://img-to-svg-six.vercel.app)에서 **배경 제거** 옵션을 선택해 투명 배경 SVG를 다시 만들면 슬라이드 배경과 자연스럽게 어우러집니다.

### SVG 파일이 열리지 않거나 깨지는 경우

PowerPoint 버전이 2016 이하이거나, 복잡한 필터(blur, clipPath 등)가 포함된 SVG일 때 발생합니다. SVG를 고해상도 PNG(300dpi 이상)로 저장해 삽입하거나 Microsoft 365로 업그레이드를 검토하세요.

### 색상이 원본과 다르게 보이는 경우

PPT가 일부 SVG 색상 프로파일을 다르게 해석할 수 있습니다. 텍스트 편집기로 SVG를 열어 `fill` 속성의 hex 코드를 확인하고 필요하면 직접 수정하세요.

## 자주 묻는 질문 (FAQ)

### Q1. 파워포인트 어떤 버전부터 SVG를 지원하나요?

Microsoft 365와 PowerPoint 2019, 2021부터 SVG를 공식 지원합니다. PowerPoint 2016은 일부 SVG만 지원하며, 2013 이하 버전에서는 SVG 삽입이 불가능합니다.

### Q2. PPT 안에서 SVG 아이콘 색상을 바꾸는 방법은?

삽입된 SVG를 우클릭 → **그룹 해제 → 예**를 선택하면 개별 도형으로 분리됩니다. 각 요소를 클릭해 채우기 색을 자유롭게 바꾼 뒤, 다시 전체 선택 후 그룹화하면 됩니다.

### Q3. PNG 로고를 SVG로 변환하면 PPT에서 품질이 좋아지나요?

단순한 로고·아이콘·일러스트는 변환 후 어떤 크기로 확대해도 선명하게 표시됩니다. 다만 사진처럼 복잡한 이미지는 벡터화 과정에서 세부 디테일이 단순화될 수 있으므로, 로고·아이콘 위주로 활용하는 것이 가장 효과적입니다.

### Q4. 구글 슬라이드에서도 SVG를 사용할 수 있나요?

네. 2023년 이후 업데이트에서 SVG 삽입을 공식 지원합니다. **삽입 → 이미지 → 컴퓨터에서 업로드** 메뉴로 불러올 수 있습니다. 단 파워포인트처럼 색상 개별 편집은 아직 제한적입니다.

### Q5. PPT를 PDF로 저장할 때도 SVG 화질이 유지되나요?

네. PPT를 PDF로 내보낼 때 SVG는 벡터 품질 그대로 변환되어 인쇄 시에도 완벽한 선명도를 유지합니다. 대형 현수막이나 고품질 인쇄물 제작에도 적합합니다.
