## PPT에 SVG를 삽입해야 하는 이유

프레젠테이션을 만들 때 로고, 아이콘, 차트 등을 PNG로 삽입하면 화면을 크게 확대할 때 이미지가 흐릿하게 깨지는 문제가 생깁니다. SVG(Scalable Vector Graphics)는 수학적 좌표로 그려지는 벡터 형식이기 때문에 **어떤 크기로 늘려도 선명도가 유지**됩니다. 특히 대형 스크린이나 4K 프로젝터에 발표할 때 SVG의 장점이 두드러집니다.

---

## SVG vs PNG — PPT 사용 시 비교

| 항목 | SVG | PNG |
|------|-----|-----|
| 확대 시 품질 | 선명함 유지 | 픽셀 깨짐 발생 |
| 파일 용량 | 보통 작음 | 해상도에 따라 큼 |
| 색상 편집 | PPT에서 직접 가능 | 불가 |
| 투명 배경 | 지원 | 지원 |
| 애니메이션 | 제한적 지원 | 미지원 |

## 파워포인트에 SVG 삽입하는 방법 (단계별)

### 1단계: SVG 파일 준비

먼저 삽입할 SVG 파일을 준비합니다. 직접 만들거나, PNG·JPG 이미지를 SVG로 변환해야 한다면 [imgtosvg](https://img-to-svg-six.vercel.app)를 이용하면 무료로 빠르게 변환할 수 있습니다.

### 2단계: PPT에 이미지 삽입

1. 파워포인트를 열고 삽입하려는 슬라이드를 선택합니다.
2. 상단 메뉴에서 **삽입 → 그림 → 이 장치**를 클릭합니다.
3. SVG 파일을 선택하고 **삽입**을 누릅니다.

> **지원 버전:** Microsoft 365, PowerPoint 2019, 2021 이상에서 SVG 삽입을 공식 지원합니다. PowerPoint 2016은 제한적으로 지원합니다.

### 3단계: SVG 크기 및 색상 조정

SVG를 슬라이드에 삽입한 뒤 자유롭게 크기를 조절해도 화질이 유지됩니다. 또한 SVG를 마우스 오른쪽 버튼으로 클릭 → **그룹 해제**를 선택하면 각 요소의 색상과 모양을 직접 편집할 수 있습니다.

## PNG/JPG 이미지를 SVG로 변환하는 방법

기존에 PNG나 JPG 형식으로 보유한 로고·아이콘을 PPT에 고품질로 삽입하려면 먼저 SVG로 변환해야 합니다.

1. [imgtosvg](https://img-to-svg-six.vercel.app) 접속
2. 변환할 PNG·JPG·WebP 파일 업로드
3. **변환 시작** 버튼 클릭
4. SVG 파일 다운로드 후 PPT에 삽입

별도 프로그램 설치 없이 브라우저에서 바로 사용할 수 있으며 완전 무료입니다.

## 자주 묻는 질문 (FAQ)

### Q1. 파워포인트에서 SVG 파일이 안 보여요.

PowerPoint 버전을 확인하세요. 2016 이하 버전은 SVG를 지원하지 않을 수 있습니다. Microsoft 365 또는 PowerPoint 2019 이상으로 업그레이드하거나, SVG를 PNG로 변환해 삽입하는 방법을 사용하세요.

### Q2. SVG를 삽입했더니 배경이 흰색으로 나와요.

변환 시 배경이 포함된 경우입니다. [imgtosvg](https://img-to-svg-six.vercel.app)에서 배경 제거 옵션을 사용해 투명 배경 SVG를 만들면 PPT 슬라이드 배경과 자연스럽게 어우러집니다.

### Q3. SVG 아이콘의 색상을 PPT에서 바꿀 수 있나요?

네, 가능합니다. SVG를 삽입한 뒤 마우스 오른쪽 버튼 → **그룹 해제** → **예**를 누르면 개별 도형으로 분리되어 채우기 색상 등을 자유롭게 변경할 수 있습니다.

### Q4. PNG 로고를 SVG로 변환하면 품질이 좋아지나요?

단순한 로고나 아이콘은 SVG 변환 후 PPT에서 훨씬 선명하게 표시됩니다. 다만 복잡한 사진 이미지는 벡터화 과정에서 디테일이 단순화될 수 있습니다.

### Q5. 구글 슬라이드에서도 SVG를 사용할 수 있나요?

구글 슬라이드는 SVG 직접 삽입을 지원하지 않습니다. PNG 또는 JPG로 변환 후 삽입하거나, SVG를 PPT로 작업한 후 공유하는 방법을 권장합니다.
