## PPT에 SVG를 삽입해야 하는 이유

발표 자료를 만들 때 로고, 아이콘, 다이어그램을 PNG로 삽입하면 대형 스크린이나 4K 프로젝터 앞에서 이미지가 흐릿하게 깨지는 문제가 발생합니다. SVG(Scalable Vector Graphics)는 수학적 좌표 기반의 벡터 형식으로 **어떤 크기로 확대해도 선명도가 완벽히 유지**됩니다.

기업 로고, UI 아이콘, 인포그래픽처럼 단순·명확한 그래픽은 SVG로 변환해 PPT에 삽입하면 파일 크기도 줄어들고 발표 품질도 훨씬 향상됩니다. 2026년 현재 Microsoft 365를 비롯한 대부분의 최신 프레젠테이션 도구가 SVG를 공식 지원하므로, 이제는 벡터 이미지 활용이 선택이 아닌 표준입니다.

## SVG vs PNG vs JPG — PPT 활용 완전 비교표

| 항목 | SVG | PNG | JPG |
|------|-----|-----|-----|
| 확대 시 품질 | 완벽히 선명함 유지 | 픽셀 깨짐 발생 | 픽셀 깨짐 + 압축 노이즈 |
| 파일 용량 | 아이콘·로고류에서 매우 작음 | 해상도에 따라 수십 MB | 중간 (손실 압축) |
| PPT 내 색상 편집 | 그룹 해제 후 직접 가능 | 불가 | 불가 |
| 투명 배경 | 기본 지원 | 지원 | 미지원 |
| 애니메이션 | 제한적 지원 (MS365) | 미지원 | 미지원 |
| 지원 버전 | Microsoft 365, PPT 2019+ | 모든 버전 | 모든 버전 |
| 인쇄 품질 | 벡터 품질 그대로 출력 | DPI에 의존 | DPI에 의존 |
| 파일 편집성 | 텍스트 편집기로 직접 수정 가능 | 불가 | 불가 |

## 파워포인트에 SVG 삽입하는 방법 (단계별)

### 1단계: SVG 파일 준비

삽입할 SVG 파일을 준비합니다. 기존에 PNG·JPG·WebP 형식의 로고나 아이콘이 있다면 먼저 SVG로 변환해야 합니다. [imgtosvg](https://img-to-svg-six.vercel.app)를 이용하면 브라우저에서 바로 무료로 변환할 수 있습니다. 별도 설치 없이 드래그 앤 드롭만으로 수 초 내 완료됩니다.

### 2단계: PPT 슬라이드에 SVG 삽입

1. 파워포인트를 열고 삽입하려는 슬라이드를 선택합니다.
2. 상단 메뉴 **삽입 → 그림 → 이 장치**를 클릭합니다.
3. 파일 탐색기에서 SVG 파일을 선택하고 **삽입**을 누릅니다.
4. 슬라이드에 SVG가 삽입되면 모서리를 드래그해 크기를 자유롭게 조절합니다.

> **지원 버전 확인:** Microsoft 365, PowerPoint 2019, 2021 이상에서 SVG를 공식 지원합니다. PowerPoint 2016은 일부 SVG만 지원하며, 2013 이하는 지원하지 않습니다.

### 3단계: SVG 색상 및 요소 편집

SVG의 강점은 PPT 내에서 색상을 직접 바꿀 수 있다는 점입니다.

1. 삽입된 SVG를 마우스 오른쪽 버튼으로 클릭합니다.
2. **그룹 해제 → 예**를 선택합니다.
3. 개별 도형으로 분리된 요소를 클릭해 **채우기 색**이나 **선 색**을 변경합니다.
4. 편집 완료 후 모든 요소를 선택해 다시 **그룹화**하면 하나의 오브젝트처럼 관리할 수 있습니다.

### 4단계: 애니메이션 및 전환 효과 적용

Microsoft 365에서는 SVG에도 애니메이션을 적용할 수 있습니다. 삽입된 SVG를 선택한 뒤 **애니메이션 탭**에서 나타내기·강조·사라지기 효과를 자유롭게 설정하세요. 그룹 해제 후 개별 경로 단위로 애니메이션을 설정하면 더욱 풍부한 연출이 가능합니다.

## 구글 슬라이드와 키노트에서 SVG 사용하기

### 구글 슬라이드

구글 슬라이드는 2023년부터 SVG 직접 삽입을 지원합니다. **삽입 → 이미지 → 컴퓨터에서 업로드** 메뉴로 SVG 파일을 불러올 수 있습니다. 단, 색상 개별 편집 기능은 아직 제한적이므로, 편집이 필요하다면 먼저 SVG 코드를 수정한 뒤 업로드하는 방법을 권장합니다.

### 애플 키노트

키노트(Keynote)는 macOS/iOS 환경에서 SVG를 완벽히 지원합니다. **삽입 → 이미지 선택**으로 SVG를 불러오면 고품질로 표시되며, 크기 조절 시에도 선명도가 유지됩니다.

## 자주 발생하는 오류와 해결 방법

### SVG 삽입 시 흰색 배경이 나타나는 경우

변환된 SVG에 배경 레이어가 포함된 경우입니다. [imgtosvg](https://img-to-svg-six.vercel.app)에서 **배경 제거** 옵션을 선택해 투명 배경 SVG를 다시 만들면 PPT 슬라이드 배경과 자연스럽게 어우러집니다.

### SVG 파일이 열리지 않거나 깨지는 경우

PowerPoint 버전이 2016 이하이거나, 특정 SVG 필터(blur, clipPath 등)가 포함된 복잡한 파일일 때 발생합니다. SVG를 고해상도 PNG(최소 300dpi)로 다시 저장해 삽입하거나, Microsoft 365로 업그레이드를 고려하세요.

### SVG 색상이 원본과 다르게 보이는 경우

PPT가 일부 SVG 색상 프로파일을 다르게 해석할 수 있습니다. SVG 파일을 텍스트 편집기로 열어 `fill` 속성값이 올바른지 확인하고, 필요하면 직접 hex 코드를 수정하세요.

## 자주 묻는 질문 (FAQ)

### Q1. 구글 슬라이드에서도 SVG를 사용할 수 있나요?

네, 구글 슬라이드는 2023년 이후 업데이트에서 SVG 삽입을 공식 지원하기 시작했습니다. **삽입 → 이미지 → 컴퓨터에서 업로드**로 SVG를 불러올 수 있습니다. 다만 파워포인트처럼 그룹 해제 후 색상 편집은 현재 기능이 제한적입니다.

### Q2. 파워포인트에서 SVG 아이콘 색상을 변경하는 방법이 있나요?

SVG를 삽입한 후 우클릭 → **그룹 해제**를 선택하면 개별 도형으로 분리됩니다. 이후 각 요소를 클릭해 채우기 색을 자유롭게 변경할 수 있습니다. 편집 후 다시 그룹화해 관리하세요.

### Q3. PNG 로고를 SVG로 변환하면 PPT에서 품질이 좋아지나요?

단순한 로고나 아이콘은 변환 후 PPT에서 훨씬 선명하게 표시되며, 어느 크기로 확대해도 깨지지 않습니다. 단, 사진처럼 복잡한 이미지는 벡터화 과정에서 세부 디테일이 단순화될 수 있으므로 로고·아이콘·일러스트에 가장 적합합니다.

### Q4. SVG 파일 용량이 PNG보다 클 때도 있나요?

복잡한 그래픽이나 사진처럼 많은 경로를 포함한 SVG는 PNG보다 용량이 클 수 있습니다. 아이콘·로고·일러스트처럼 비교적 단순한 그래픽에 SVG를 활용하는 것이 가장 효과적입니다.

### Q5. PPT 파일을 PDF로 저장할 때도 SVG 품질이 유지되나요?

네. PPT를 PDF로 내보낼 때 SVG는 벡터 품질 그대로 변환되어 인쇄 시에도 선명도가 완벽히 유지됩니다. 고품질 발표 자료 인쇄나 대형 현수막 제작에도 적합합니다.

### Q6. 무료로 SVG를 구할 수 있는 방법이 있나요?

Flaticon, SVG Repo, Font Awesome 같은 사이트에서 무료 SVG 아이콘을 다운로드할 수 있습니다. 직접 보유한 PNG·JPG 이미지가 있다면 [imgtosvg](https://img-to-svg-six.vercel.app)로 즉시 SVG로 변환해 사용하세요.
