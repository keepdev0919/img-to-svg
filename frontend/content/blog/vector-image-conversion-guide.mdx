## 벡터 이미지 변환이란?

**벡터 이미지 변환(Vectorization)**은 픽셀 기반 래스터 이미지(PNG·JPG·WebP)를 수학적 경로(Path)로 구성된 SVG 포맷으로 바꾸는 과정입니다. 래스터 이미지는 확대하면 깨지지만, 벡터(SVG)는 어떤 크기로 확대해도 선명함을 유지합니다.

명함 크기 로고를 빌보드 현수막에, 웹 아이콘을 레티나 디스플레이에 사용할 때 벡터 변환이 반드시 필요한 이유입니다.

## 래스터 vs 벡터 — 핵심 차이 완전 비교

| 비교 항목 | 래스터 (PNG · JPG · WebP) | 벡터 (SVG) |
|----------|--------------------------|-----------|
| 확대 시 품질 | 픽셀화·흐릿해짐 | 무한 확대해도 선명 |
| 파일 크기 | 해상도에 비례해 증가 | 단순 도형일수록 소형 |
| 색상 표현 | 수백만 색 (사진에 적합) | 주로 단색·그라디언트 |
| 웹 성능 최적화 | 별도 최적화 필요 | 텍스트 기반, gzip 압축 탁월 |
| CSS/JS 동적 제어 | 불가 | fill·stroke 동적 변경 가능 |
| 편집 도구 | 포토샵, GIMP | 일러스트레이터, 피그마, Inkscape |
| 인쇄 적합성 | 고해상도 원본 필요 | 해상도 무관, 무한 확대 가능 |
| 애니메이션 | 불가 (GIF 제외) | CSS·JS로 경로 직접 애니메이션 |
| 주요 용도 | 사진, 스크린샷, 복잡한 이미지 | 로고, 아이콘, UI, 일러스트 |

## 벡터 변환이 꼭 필요한 7가지 상황

### 1. 로고·브랜드 아이덴티티
명함·브로셔·웹사이트·간판에 동시에 쓰이는 로고는 벡터 포맷이 필수입니다. 해상도에 관계없이 항상 선명하게 출력됩니다.

### 2. UI 아이콘 개발
SVG 아이콘은 CSS `fill` 속성 하나로 다크 모드·브랜드 컬러 대응이 가능합니다. 반응형 레이아웃에서도 해상도 걱정이 없습니다.

### 3. 대형 인쇄 출력물
플렉스 배너·현수막·포스터는 300dpi 이상을 요구합니다. 벡터는 어떤 크기로도 인쇄할 수 있습니다.

### 4. 피그마·일러스트레이터 추가 편집
SVG로 불러오면 레이어·경로 구조가 유지되어 색상·형태 세부 편집이 수월합니다.

### 5. 웹 성능 최적화 (Core Web Vitals)
단순 아이콘·로고는 SVG가 PNG보다 파일 크기가 작아 LCP·CLS 점수를 직접적으로 개선합니다.

### 6. 애니메이션·인터랙션 구현
CSS `@keyframes` 또는 GSAP으로 경로를 직접 애니메이션화할 수 있습니다. 로딩 스피너, 호버 이펙트에 적합합니다.

### 7. 이메일 서명·문서 삽입
Word·Google Docs·PPT에 삽입할 때 SVG는 확대·축소해도 깨지지 않아 고품질 문서를 만들 수 있습니다.

## 단계별 벡터 변환 가이드 (imgtosvg 기준)

### Step 1 — 원본 이미지 준비
고품질 결과를 위해 **512px 이상 해상도**의 PNG 또는 WebP를 준비하세요. 투명 배경이 있는 PNG면 더욱 좋습니다. 배경이 복잡하다면 먼저 배경 제거를 진행하세요.

### Step 2 — imgtosvg 접속 및 업로드
[https://img-to-svg-six.vercel.app](https://img-to-svg-six.vercel.app)에 접속합니다. 회원가입·로그인·설치 불필요. 파일을 드래그 앤 드롭하거나 클릭해 선택합니다.

### Step 3 — 변환 옵션 설정
- **색상 수:** 로고·아이콘은 4~8색으로 충분. 줄일수록 파일이 작고 깔끔해집니다.
- **곡선 정확도:** 높일수록 원본에 가깝지만 파일 크기가 커집니다.
- **배경 제거:** 투명 배경 SVG가 필요하면 반드시 활성화하세요.

### Step 4 — 미리보기 확인 및 다운로드
변환된 SVG 미리보기를 확인하고, 만족스러우면 즉시 다운로드합니다. 결과가 마음에 들지 않으면 옵션을 조정해 재변환하세요.

## 변환된 SVG 활용 방법

- **웹사이트 삽입:** `<img src="logo.svg">` 또는 인라인 `<svg>...</svg>`로 직접 임베드
- **피그마 임포트:** File → Place Image → SVG 파일 선택
- **파워포인트 삽입:** 삽입 → 그림 → SVG 파일 선택 (확대·축소해도 깨짐 없음)
- **CSS 스타일 제어:** `fill`, `stroke` 속성으로 색상 동적 변경
- **인쇄소 제출:** SVG 또는 AI 포맷 요구 인쇄소에 바로 제출 가능
- **애니메이션 적용:** CSS `@keyframes` 또는 GSAP으로 경로 애니메이션 구현
- **이메일·문서:** Outlook·Gmail 서명, Word·Google Docs에 고품질 로고 삽입

## 자주 묻는 질문 (FAQ)

### Q1. 사진도 벡터로 변환할 수 있나요?
사진처럼 색상이 수천 가지인 이미지는 SVG 품질이 낮을 수 있습니다. 벡터 변환은 **단순한 로고·아이콘·일러스트·텍스트 이미지**에 가장 적합합니다. 복잡한 사진은 색상 수를 줄이거나 포스터화 처리 후 변환하면 더 나은 결과를 얻을 수 있습니다.

### Q2. 무료 변환에 파일 수 제한이 있나요?
imgtosvg는 회원가입 없이 **무제한 무료 변환**을 제공합니다. 설치나 결제 없이 바로 사용 가능합니다.

### Q3. 변환 후 SVG 파일 크기가 너무 크면 어떻게 하나요?
색상 수를 줄이거나 **SVGO** 같은 최적화 도구로 후처리하면 파일 크기를 50~80% 줄일 수 있습니다. SVGO는 불필요한 메타데이터와 중복 경로를 자동 제거합니다.

### Q4. 일러스트레이터 없이 SVG를 편집할 수 있나요?
네. **Inkscape**(무료 오픈소스), **피그마 무료 플랜**, VS Code의 SVG 미리보기 확장을 사용하세요. SVG는 텍스트 기반이므로 메모장·VS Code에서 코드를 직접 수정할 수도 있습니다.

### Q5. PNG와 WebP 중 변환 품질이 더 좋은 포맷은?
포맷보다 **해상도와 색상 단순도**가 더 중요합니다. 고해상도(최소 512×512px) 투명 배경 PNG가 일반적으로 가장 깔끔한 SVG 결과를 만들어냅니다.

### Q6. 변환된 SVG를 상업적으로 사용해도 되나요?
원본 이미지의 저작권을 본인이 보유하고 있다면 변환 결과물도 자유롭게 상업적으로 사용할 수 있습니다. imgtosvg는 변환된 파일에 대한 저작권을 주장하지 않습니다.

### Q7. JPG를 벡터로 변환하면 배경이 같이 변환되나요?
JPG는 투명 배경을 지원하지 않으므로 흰색 또는 단색 배경이 함께 변환됩니다. imgtosvg의 **배경 제거 기능**을 활성화하면 AI가 자동으로 배경을 제거하고 투명 SVG를 생성해 줍니다.
