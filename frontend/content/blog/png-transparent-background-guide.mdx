## PNG 투명 배경이란? — 기초부터 이해하기

PNG(Portable Network Graphics)는 **알파 채널**을 지원하는 유일한 주요 래스터 이미지 형식입니다. 알파 채널은 픽셀별 투명도 정보를 저장하며, 0(완전 투명)부터 255(완전 불투명) 사이의 값을 가집니다.

투명 배경 PNG를 활용하면 다음이 가능합니다.

- 웹사이트 헤더·로고를 어떤 배경색에도 자연스럽게 합성
- SNS 카드·썸네일 제작 시 배경 없이 피사체만 배치
- 프레젠테이션 슬라이드에 전문적인 합성 이미지 삽입
- 이커머스 상품 사진의 배경을 흰색·투명으로 통일

## 방법별 단계별 가이드

### 방법 1: imgtosvg — 무료 AI 온라인 도구 (추천)

가장 빠르고 설치가 필요 없는 방법입니다. PNG, JPG, WebP를 업로드하면 AI가 배경을 자동으로 인식해 제거하며, 투명 PNG 또는 SVG로 다운로드할 수 있습니다.

1. **[imgtosvg](https://img-to-svg-six.vercel.app)** 에 접속합니다.
2. 이미지를 드래그 앤 드롭하거나 **파일 선택** 버튼으로 업로드합니다.
3. AI가 피사체와 배경을 자동 분리합니다.
4. **투명 PNG** 또는 **SVG** 형식으로 다운로드합니다.

> 회원가입 없음 · 워터마크 없음 · 완전 무료

### 방법 2: GIMP — 무료 데스크톱 소프트웨어

1. GIMP 설치 후 이미지를 엽니다.
2. **이미지 → 알파 채널 추가** 를 선택합니다. (없으면 투명도 저장 불가)
3. **퍼지 선택 도구(U)** 로 배경을 클릭합니다.
4. `Delete` 키로 선택된 배경을 삭제합니다.
5. **파일 → 다른 이름으로 내보내기** 에서 `.png` 로 저장합니다.

**팁:** 배경색이 피사체와 비슷한 경우 **경계 선택 다듬기(Grow/Feather)** 기능을 활용하면 가장자리를 부드럽게 처리할 수 있습니다.

### 방법 3: 포토샵 자동 배경 제거 (AI 활용)

1. 포토샵에서 이미지를 열고 레이어를 일반 레이어로 변환합니다.
2. **속성 패널 → 빠른 작업 → 배경 제거** 를 클릭합니다.
3. Adobe AI(Sensei)가 자동으로 피사체를 마스킹합니다.
4. **파일 → 내보내기 → PNG로 내보내기** 를 선택합니다.

## 투명 PNG를 SVG로 변환하면 더 강력해지는 이유

| 특성 | 투명 PNG | 투명 SVG |
|------|----------|----------|
| 확대 시 품질 | 해상도 의존 | **무손실 무한 확대** |
| 파일 크기 (단순 이미지) | 보통 | **더 작음** |
| CSS/JS 제어 | 불가 | **색상·애니메이션 가능** |
| 인쇄 품질 | 제한적 | **인쇄소 바로 사용 가능** |
| 웹 SEO | 불가 | **내부 텍스트 크롤링 가능** |

로고, 아이콘, 일러스트처럼 단순한 이미지라면 투명 PNG보다 SVG 변환을 강력히 권장합니다.

## 자주 묻는 질문 (FAQ)

### Q1. JPG 파일을 투명 배경으로 만들 수 있나요?

JPG 형식 자체는 투명도를 지원하지 않습니다. 하지만 JPG 이미지에서 배경을 제거한 뒤 **PNG 또는 SVG 형식으로 저장**하면 투명 배경을 유지할 수 있습니다. imgtosvg에서 JPG를 업로드해도 투명 PNG·SVG로 출력할 수 있습니다.

### Q2. 투명 배경 PNG가 흰색으로 보이는 이유는?

이미지 뷰어나 브라우저 배경이 흰색이기 때문에 투명 영역이 흰색으로 보이는 것입니다. 실제 투명도가 적용되었는지 확인하려면 **체크무늬 배경**이 표시되는 그래픽 편집 도구(GIMP, Photoshop, Figma)에서 열어보세요.

### Q3. 피사체 가장자리가 지저분하게 처리될 때 해결책은?

AI 도구는 대부분 자동으로 처리하지만, 머리카락이나 복잡한 배경의 경우 품질이 낮을 수 있습니다. 이때는 GIMP의 **경계 다듬기**, 포토샵의 **선택 및 마스크(Select and Mask)** 기능을 추가로 사용해 수동으로 보정하세요.

### Q4. 투명 PNG를 파워포인트에 삽입하면 투명도가 유지되나요?

네, 유지됩니다. PNG 투명 배경은 파워포인트·키노트·구글 슬라이드 모두에서 투명도가 그대로 반영됩니다. 단, 파일을 JPEG로 내보내면 투명 영역이 흰색으로 채워지니 주의하세요.

### Q5. 배경 제거 결과를 상업적으로 사용해도 되나요?

imgtosvg로 처리한 이미지의 저작권은 원본 이미지 소유자에게 있습니다. 직접 촬영한 사진이나 저작권 없는 이미지를 사용한다면 상업적 활용도 문제없습니다. 스톡 이미지를 사용할 경우 해당 라이선스를 꼭 확인하세요.
