## PNG 투명 배경이란? — 알파 채널의 원리

PNG(Portable Network Graphics)는 픽셀마다 **알파(alpha) 채널**을 저장할 수 있는 이미지 형식입니다. 알파값이 0이면 완전 투명, 255면 완전 불투명 — 그 사이 어느 값이든 반투명 효과를 표현할 수 있습니다.

JPEG는 알파 채널을 지원하지 않기 때문에, 투명 배경이 필요하다면 반드시 **PNG 또는 SVG** 형식을 사용해야 합니다.

### 투명 배경 PNG가 꼭 필요한 상황

- **웹사이트 로고** — 어떤 배경색 위에도 자연스럽게 어울림
- **SNS 카드·썸네일** — 피사체만 잘라내어 원하는 배경에 배치
- **이커머스 상품 사진** — 배경을 흰색·투명으로 통일해 전문적 느낌 연출
- **프레젠테이션 슬라이드** — 슬라이드 배경과 이음새 없이 자연스럽게 삽입
- **스티커·굿즈 디자인** — 외곽선만 남기고 인쇄소에 바로 납품

## 방법 2: GIMP — 무료 데스크톱 소프트웨어

### 단색 배경 빠른 제거

1. GIMP를 설치하고 이미지를 엽니다.
2. 메뉴 **이미지 → 알파 채널 추가**를 선택합니다. (이 단계를 건너뛰면 투명도 저장 불가)
3. 도구 상자에서 **퍼지 선택 도구(U)**를 선택합니다.
4. 배경 영역을 클릭해 선택하고, `Delete` 키로 삭제합니다.
5. **파일 → 다른 이름으로 내보내기**에서 `.png` 확장자로 저장합니다.

### 복잡한 배경 처리 팁

| 기능 | 용도 |
|------|------|
| 색상으로 선택(Select by Color) | 여러 색상이 섞인 배경에 효과적 |
| 경계 다듬기(Feather) | 가장자리를 자연스럽게 블렌딩 |
| 성장/축소(Grow/Shrink) | 선택 영역 미세 조정 |
| 경로 도구(Paths) | 복잡한 형태의 정밀 선택 |

## 방법 3: 포토샵 AI 자동 배경 제거

### Adobe AI(Sensei) 활용

1. 이미지를 열고 잠긴 배경 레이어를 **일반 레이어로 변환** (레이어 더블클릭)합니다.
2. **속성(Properties) 패널 → 빠른 작업 → 배경 제거**를 클릭합니다.
3. Adobe AI가 자동으로 피사체를 마스킹합니다.
4. 결과가 마음에 들지 않으면 **선택 및 마스크(Select and Mask)**로 세밀하게 수정합니다.
5. **파일 → 내보내기 → PNG로 내보내기**를 선택합니다.

> **주의:** 포토샵은 월 구독료가 발생합니다. 단순 배경 제거 목적이라면 무료 도구를 먼저 활용해 보세요.

## 투명 PNG vs 투명 SVG — 언제 무엇을 써야 할까?

| 특성 | 투명 PNG | 투명 SVG |
|------|----------|----------|
| 확대 시 품질 | 픽셀 깨짐 발생 | **무한 확대 무손실** |
| 파일 크기 (단순 이미지) | 보통 | **훨씬 작음** |
| CSS로 색상 변경 | 불가 | **가능** |
| 애니메이션 효과 | 불가 | **가능 (SMIL, CSS)** |
| 인쇄·인쇄소 납품 | 해상도 의존 | **벡터라 해상도 무관** |
| 웹 접근성 | alt 텍스트만 | **내부 텍스트 크롤링** |
| 복잡한 사진 이미지 | **적합** | 부적합 |
| 브라우저 지원 | 모든 브라우저 | 모든 현대 브라우저 |

**로고, 아이콘, 일러스트처럼 선·면으로 구성된 이미지라면 SVG가 훨씬 유리합니다.**

## 자주 묻는 질문 (FAQ)

### Q1. JPG 이미지도 투명 배경으로 만들 수 있나요?

JPG 형식 자체는 투명도를 지원하지 않습니다. 하지만 JPG를 업로드해 배경을 제거한 뒤 **PNG 또는 SVG로 저장**하면 투명 배경을 얻을 수 있습니다. imgtosvg는 JPG, WebP 업로드를 모두 지원합니다.

### Q2. 투명 배경 PNG가 흰색으로 보이는 이유는?

뷰어나 브라우저의 기본 배경색이 흰색이기 때문입니다. 실제 투명도 적용 여부를 확인하려면 **체크무늬 배경이 표시되는 편집 도구**(GIMP, Figma, Photoshop)에서 열어보거나, 다른 색 배경 위에 이미지를 올려보세요.

### Q3. 머리카락·털처럼 복잡한 가장자리도 깔끔하게 처리되나요?

AI 도구는 단색 배경에서 매우 정확하지만, 미세한 머리카락이나 복잡한 배경에서는 품질이 다소 떨어질 수 있습니다. 이때는 포토샵의 **선택 및 마스크 → 가장자리 다듬기**, GIMP의 **경계 다듬기(Feather)** 기능으로 수동 보정하는 것이 효과적입니다.

### Q4. 투명 PNG를 파워포인트에 삽입하면 투명도가 유지되나요?

네, 유지됩니다. PNG 투명 배경은 파워포인트·키노트·구글 슬라이드 모두에서 그대로 반영됩니다. 단, 발표 파일을 **JPEG로 내보내면 투명 영역이 흰색으로 채워지므로** PDF 또는 PNG 형식으로 내보내세요.

### Q5. 배경 제거 후 파일 크기가 너무 크면 어떻게 줄이나요?

투명 PNG는 알파 채널 데이터 때문에 파일 크기가 커질 수 있습니다. **SVG로 변환**하면 로고·아이콘 같은 단순한 이미지는 파일 크기가 크게 줄어듭니다. 또는 TinyPNG 같은 PNG 압축 도구를 추가로 활용하세요.

### Q6. 배경 제거한 이미지를 상업용으로 써도 되나요?

툴 자체의 사용 제한은 없지만, **원본 이미지의 저작권**을 반드시 확인해야 합니다. 본인이 직접 촬영하거나 CC0·퍼블릭 도메인 이미지를 사용한 경우라면 상업 활용이 가능합니다. 스톡 이미지는 해당 플랫폼의 라이선스 조건을 확인하세요.

### Q7. WebP 이미지도 투명 배경 처리가 되나요?

네, WebP는 PNG처럼 알파 채널을 지원하므로 투명도 처리가 가능합니다. imgtosvg는 WebP 업로드를 지원하며, 배경 제거 후 투명 PNG 또는 SVG로 출력할 수 있습니다.
