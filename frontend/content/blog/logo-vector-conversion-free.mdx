## 왜 로고는 반드시 벡터 파일이어야 할까?

명함, 현수막, 웹사이트, 앱 아이콘은 각기 다른 크기로 로고를 요구합니다. PNG·JPG처럼 픽셀로 이루어진 **래스터 이미지**는 원본보다 크게 확대하면 계단 현상(픽셀 깨짐)이 발생합니다. 반면 **SVG(벡터)** 는 수학적 경로로 그려지기 때문에 스마트폰 화면부터 대형 현수막까지 언제나 선명합니다.

인쇄소에서 "벡터 파일로 보내주세요"라는 말을 들었다면, 바로 SVG·AI·EPS 같은 벡터 포맷을 요청하는 것입니다.

## 래스터 vs 벡터 — 로고 사용 시 비교

| 항목 | PNG / JPG (래스터) | SVG (벡터) |
|------|-------------------|------------|
| 확대 시 품질 | 픽셀 깨짐 발생 | 항상 선명 |
| 파일 크기 | 보통 큼 | 단순 로고는 매우 작음 |
| 인쇄 적합성 | 고해상도 PNG 필요 | 해상도 무관 |
| 웹 로딩 속도 | 파일 클수록 느림 | 가볍고 빠름 |
| 편집 가능성 | 제한적 | Figma·Illustrator에서 자유롭게 편집 |
| 투명 배경 지원 | PNG만 가능 | 기본 지원 |
| 무료 변환 도구 | — | imgtosvg 이용 가능 |

## 로고를 고품질 SVG로 변환하는 단계별 가이드

### 1단계 — 최적의 원본 파일 준비

변환 품질은 원본 파일에 달려 있습니다. 아래 조건을 갖추면 변환 결과가 훨씬 좋아집니다.

- **해상도:** 최소 500×500 px 이상 (고해상도일수록 윤곽선이 정확하게 추출됨)
- **배경:** 흰색 단색 또는 투명 배경 PNG가 이상적
- **색상 수:** 적을수록 깔끔한 SVG 생성 — 단색·2~3색 로고에 최적
- **불필요한 여백 제거:** 크롭 후 업로드하면 변환 정밀도 향상

### 2단계 — imgtosvg에서 변환

[imgtosvg](https://img-to-svg-six.vercel.app)에 접속해 PNG·JPG·WebP 로고 파일을 드래그하거나 클릭해 업로드합니다. 업로드 즉시 자동으로 벡터화가 시작되며, 별도 설정이나 회원가입이 필요 없습니다.

### 3단계 — 배경 제거 (필요 시)

로고 주변에 흰색 배경이 포함되어 있다면, imgtosvg의 **배경 제거 기능**을 먼저 활용하세요. 투명 배경으로 만든 뒤 SVG로 변환하면 어두운 배경이나 색상 배경 위에서도 로고가 깔끔하게 표시됩니다.

### 4단계 — 미리보기 확인 후 다운로드

변환된 SVG 미리보기를 화면에서 확인하고, 결과가 만족스러우면 **다운로드** 버튼을 클릭합니다. 완전 무료이며 워터마크가 없습니다.

### 5단계 — 변환된 SVG 활용

| 활용처 | 사용 방법 |
|--------|----------|
| 웹사이트 | `<img src="logo.svg">` 또는 인라인 SVG 삽입 |
| Figma | 파일 메뉴 → 가져오기(Import) |
| PowerPoint | 삽입 → 그림 → 디바이스에서 |
| 인쇄소 제출 | SVG를 Illustrator에서 열어 AI·PDF로 내보내기 |
| 앱 아이콘 | Android·iOS 모두 SVG 지원 |

## 변환 품질을 높이는 실전 팁

- **그라데이션 로고는 단순화 먼저:** 그라데이션이 많은 로고는 SVG 경로가 복잡해집니다. 가능하면 단색·플랫 디자인으로 단순화한 뒤 변환하세요.
- **텍스트가 포함된 로고:** 변환 후 텍스트 부분이 경로(path)로 변환됩니다. 폰트 정보는 사라지므로 나중에 Figma에서 텍스트를 다시 입력하는 것을 권장합니다.
- **SVG 최적화:** 변환 후 [SVGOMG](https://jakearchibald.github.io/svgomg/)에서 파일을 최적화하면 웹 로딩 속도가 더욱 빨라집니다.
- **색상 수 줄이기:** 색상이 많으면 변환 후 Figma나 Inkscape에서 색상을 병합해 파일 크기를 줄이세요.

## 자주 묻는 질문 (FAQ)

### Q1. 무료로 로고를 벡터로 변환할 수 있나요?

**A.** 네. [imgtosvg](https://img-to-svg-six.vercel.app)에서 PNG·JPG·WebP 로고를 무료로 SVG로 변환할 수 있습니다. 소프트웨어 설치나 회원가입 없이 브라우저에서 바로 사용 가능합니다.

### Q2. 변환된 SVG를 Adobe Illustrator나 Figma에서 편집할 수 있나요?

**A.** 네. SVG는 Adobe Illustrator, Figma, Inkscape 등 주요 벡터 편집 프로그램에서 모두 지원합니다. 변환 후 색상·크기·모양을 자유롭게 수정할 수 있습니다.

### Q3. 사진처럼 복잡한 이미지도 로고 SVG로 변환할 수 있나요?

**A.** 변환은 되지만 결과물이 복잡해집니다. SVG 벡터 변환은 단순한 로고, 아이콘, 픽토그램에 최적화되어 있습니다. 사진 이미지라면 단순화하거나 배경 제거 후 변환을 시도하세요.

### Q4. 변환 후 파일 용량이 원본보다 커졌어요. 왜인가요?

**A.** 색상이 많거나 복잡한 이미지를 SVG로 변환하면 수많은 경로(path) 데이터가 생성되어 용량이 커질 수 있습니다. 단순한 로고는 PNG보다 훨씬 작아지는 경우가 대부분입니다.

### Q5. 인쇄소에서 요구하는 벡터 파일 형식이 SVG인가요?

**A.** SVG도 벡터 파일이지만, 국내 인쇄소는 주로 AI(Adobe Illustrator)·EPS·PDF 벡터 포맷을 요구합니다. imgtosvg로 SVG를 만든 뒤 Illustrator에서 열어 AI 또는 PDF로 내보내면 인쇄 제출용으로 사용할 수 있습니다.
